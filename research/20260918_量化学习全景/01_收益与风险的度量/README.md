## 一、这节课学什么

学完本节课（约 40 分钟）你应该能：

1. 说清楚**简单收益率**和**对数收益率**的区别：一个"截面可加"、一个"时序可加"，并知道什么时候该用哪个；
2. 亲手算出并解释四个收益指标：**区间累计收益、年化收益（244交易日）、年化波动率、下行波动率**；
3. 用三个比率给"性价比"打分：**夏普、索提诺、卡玛**，并理解为什么夏普要减无风险利率；
4. 画出**回撤三线图**，报告最大回撤、发生区间、回撤修复天数；
5. 理解尾部风险的两把尺子 **VaR 与 ES** 的区别，并能在收益率分布图上指出来。

一句话总纲：**收益看"几何年化"，风险看"波动率 + 回撤 + 尾部"，性价比看"超额收益/风险"。**

## 二、核心概念（公式 + 直观解释）

### 2.1 简单收益率 vs 对数收益率

```
简单收益率   r_t = P_t / P_{t-1} - 1
对数收益率   l_t = ln(P_t / P_{t-1}) = ln(1 + r_t)
```

- **对数收益率时序可加**：把每天的 `l_t` 直接相加就是整个区间的总对数收益，
  `exp(Σl_t) = ∏(1+r_t)`，所以"用对数收益重建净值"和"简单收益复利"结果**一模一样**——
  图1 中蓝色实线（复利净值）与橙色虚线（对数净值）完全重合，两者期末净值都是 **1.404**（平安银行）/ **1.509**（沪深300）。
- **简单收益率截面可加**：某一天组合里有 60% 平安银行 + 40% 沪深300，组合当日收益就是
  `0.6·r_股票 + 0.4·r_指数`。对数收益率做不到这一点（`ln` 会破坏加权关系）。
- **什么时候用哪个**：
  - 跨期的事（算净值、回撤、复利、给收益率建时序模型、年化）→ 用对数收益率；
  - 同一时点跨资产的事（组合权重加权、横截面统计、业绩归因）→ 用简单收益率；
  - 日频下收益很小，`ln(1+r) ≈ r`，两者数值几乎一样，但**加总规则完全不同**。
- **反面教材**（图1 红线）：把日简单收益率按时序直接累加 `1+Σr_t`，
  平安银行得到 **1.853**、沪深300 得到 **1.698**，都明显高于真实复利净值（1.404 / 1.509）。
  原因是这种加法忽略了复利与"波动拖累"（涨跌交叉项大多为负），**系统性高估收益**。

### 2.2 年化收益与年化波动率：为什么是 √244

```
年化收益（几何口径，A股惯例一年244个交易日）
    R_ann = 净值^(244/N) - 1          （N 为样本交易日数）
年化波动率
    σ_ann = std(日收益, ddof=1) × √244
```

- **为什么乘 √244 而不是 ×244？** 在"日收益独立同分布"的近似下，T 天的收益**方差**是日方差的 T 倍
  （方差可加），而波动率是方差的**开根号**，所以放大 √T 倍。A 股一年约 244 个交易日，故 ×√244。
- **数量级感受**：平安银行日波动率 = 29.74%/√244 ≈ 1.90%，沪深300 ≈ 1.42%。
  日频数字看着温顺，年化后一个是 **29.74%**、一个是 **22.12%**——这就是必须年化的原因。
  若错误地"年化 = 日波动 × 244"，会得出 464% 这种荒谬数字。
- **年化收益用几何口径**（复利折算，`1.404^(244/2842)-1 = 2.95%`），因为它回答
  "每年稳定复利多少才能走到期末净值"；算术口径（日均×244）会因波动拖累而系统性偏高。
- **下行波动率**：`√( mean( min(r - MAR, 0)² ) ) × √244`，本课 MAR=0，即**只有亏损日才算风险**，
  上涨日以 0 计入（不是直接剔除）。平安银行 **19.89%**、沪深300 **15.87%**，都小于全波动率
  （29.74% / 22.12%），因为上涨日贡献的那部分波动被剔除了。

### 2.3 三个"性价比"比率

```
夏普比率   Sharpe  = (R_ann - rf) / σ_ann        rf = 2%
索提诺比率 Sortino = (R_ann - rf) / 下行波动率
卡玛比率   Calmar  = R_ann / |最大回撤|
```

- **为什么夏普要减无风险利率 rf？** 因为把钱买国债/货基也能白拿约 2%，这部分收益不需要任何冒险。
  承担波动换来的"酬劳"只有**超出无风险的部分**（超额收益）。不减 rf，高利率环境下的理财都能"躺赢"，比率的区分度就没了。
- **索提诺 vs 夏普**：分母从全波动率换成下行波动率，只惩罚亏损方向的波动。
  同一份数据索提诺永远 ≥ 夏普（分母更小）：平安 0.05 vs 夏普 0.03，沪深300 0.10 vs 0.07。
- **卡玛**：把"历史最痛的一跌"当风险标尺，适合评估趋势/配置类策略的深度回撤承受力。
- **读数**：两只的夏普都只有 0.03 / 0.07——2015 年高点附近进场、拿到 2026 年，
  每扛住 1 单位波动只换来约 0.03~0.07 单位超额收益。**收益不差，但风险代价大**，这就是本课想让你看见的东西。

### 2.4 最大回撤（三线图：净值 / 历史高点 / 回撤）

```
回撤序列   DD_t = 净值_t / 历史最高净值 - 1   （≤0）
最大回撤   MDD = min(DD_t)
```

- 实际运行结果：
  - **平安银行 MDD = -62.34%**，区间 2021-05-26（峰）→ 2023-12-20（谷），**至今未修复**（截至 2026-09-16）；
  - **沪深300 MDD = -45.45%**，区间 2015-06-08 → 2016-01-28，**2020-08-28 才收复**——用了约 4 年半；
  - 最长回撤修复天数（按交易日）：平安银行 **1289 天**（2021-05-26 起，未修复），沪深300 **1355 天**（2021-02-10 起，未修复）。
- 直观解释：`cummax`（历史高点线）只会往上走；净值跌下去后，回撤图上就是一片"水下区域"。
  **回撤修复天数告诉你"解套要多久"**——它比波动率更接近真实持有体验。

### 2.5 VaR 与 ES：门槛与门后的深渊

```
历史法 VaR(95%) = 日收益的 5% 分位数（取绝对值表示亏损幅度）
历史法 ES(95%)  = 所有 ≤ 该分位数的交易日的平均亏损
```

- **区别一句话**：VaR 告诉你"最差的 5% 日子**从多深开始**"（一道门槛），ES 告诉你"一旦越过门槛，**平均有多深**"（条件期望）。ES 永远 ≥ VaR，且对尾部更诚实。
- 实际结果（日频）：平安银行 VaR95 = **2.76%**、ES95 = **4.17%**、VaR99 = **5.11%**、ES99 = **6.91%**；
  沪深300 VaR95 = **1.98%**、ES95 = **3.43%**、VaR99 = **4.43%**、ES99 = **6.50%**。
  注意 ES95 比 VaR95 深约 1.2~1.5 个百分点——**尾部不是"刚过线一点点"，而是平均深得多**。
- 正确读法：平安银行 VaR95 = 2.76% 的意思是"正常情况下，约 95% 的交易日单日亏损不超过 2.76%"，
  而剩下 5% 的日子里**平均亏 4.17%**，历史最极端的单日亏损超过 10%。
- 历史法的隐含假设是"历史会重演"：它完全由已发生的样本分位数决定，对没发生过的危机没有想象力。

### 2.6 滚动 60 日年化波动率：波动率聚集

```
σ_roll(t) = std(最近60日收益) × √244
```

图4 中曲线在 2015 年股灾、2018 年贸易摩擦、2020 年疫情、2022 年、2024 年 9 月行情里**成串冲高**
（平安银行最高 **63.35%**，沪深300 最高 **69.76%**），在 2016-2017 等平静期**成串趴底**
（最低 **8.02%** / **7.22%**）。这就是**波动率聚集**：大波动跟着大波动，小波动跟着小波动。
它是后面 GARCH（第13课）能"预测"波动率的根本原因，也是"波动率目标配置"（第10课）可行的前提。

## 六、常见的坑

1. **用日波动率/日VaR直接比大小，或年化时乘 244 而不是 √244**。
   日波动 1.90% vs 1.42% 看着只差一点点，年化后是 29.74% vs 22.12%；而"×244"会得出 464% 的荒谬结果。
   比较风险前先统一时间尺度：波动率 ×√244，收益 ×244（几何口径另算）。
2. **忽略复权**。除权除息日股价会"跳水"，用不复权价格会看到假暴跌、算出假收益，
   长期累计收益被大幅歪曲（本工作区 2026-09-05 的十倍股研究就出现过复权值虚增的实例）。
   本课数据是**前复权**的——换数据源时第一件事就是确认复权方式。
3. **把最大回撤当"未来必然回撤"，或反过来以为"跌成这样不会再有"**。
   MDD 是**样本内**统计：只看 2015-2020 的平安银行，你根本看不到 -62.34%（它发生在 2021-2023）；
   而图2里"未修复"三个字提醒你——单票回撤可以五年多不解套，回撤不是回声，是真实损失。
4. **把日简单收益率跨期直接相加**（图1红线）：平安银行 1.853 vs 真实 1.404。
   同理，"日均收益×244"的算术年化也会系统性高估，年化请用几何口径。
5. **把 VaR 当"最坏情况"**。VaR95=2.76% 只是"95% 的日子不超过 2.76%"，
   越线之后**平均**亏 4.17%（ES95），历史极端日亏过 10% 以上。风控看 ES，压力测试看情景。

## 七、延伸思考（练习）

1. **改 MAR**：把 `main.py` L47 的 `MAR = 0.0` 改成 `MAR = RISK_FREE / TRADING_DAYS`（即 rf/244），
   重跑后对比下行波动率与索提诺比率的变化，想一下"分母口径变了，比较对象还公平吗"。
2. **参数法 vs 历史法**：假设日收益服从正态分布，参数法 VaR95 ≈ `1.645×σ_日 - μ_日`
   （平安银行 σ_日 ≈ 29.74%/√244 ≈ 1.90%）。算出来与历史法 2.76% 差多少？
   再用 99% 分位比一比——正态假设在 95% 和 99% 处的误差方向一样吗？（提示：尖峰肥尾。）
3. **换标的、分段看**：把 `STOCK_CSV` 换成 `data/cache/` 里的贵州茅台、比亚迪或中信证券重跑，
   观察卡玛比率排序；再把样本切成 2015-2020 与 2021-2026 两段，看同一只股票的夏普/回撤
   在两段里差多少——体会"样本选择决定你看到的世界"。
