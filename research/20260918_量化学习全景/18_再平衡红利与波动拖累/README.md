# 18 再平衡红利与波动拖累 —— 再平衡到底赚的是什么钱？

> 单文件 `main.py` 自包含，随机种子 42，实测运行约 4 秒（退出码 0）。
> 数据：`../data/cache/` 的 10 个真实行业板块（共同重叠期 2021-12-29 ~ 2026-09-16，1119 个交易日）。
> 本课回答三个问题：① 波动的"数学成本"从哪来？② Shannon's demon 为什么说波动本身能被"收割"？③ 真实 A 股行业数据上，再平衡频率怎么选、红利到底有多大？

## 0. 这节课学什么

"再平衡赚的是什么钱"是一个被大量误解的问题。常见说法有两种极端：
"再平衡是免费午餐，定期再平衡稳赚超额" 与 "再平衡只是把组合拉回目标权重，不创造收益"。两种都不对。

这节课把这件事拆成四层：

1. **数学打底**：先理解"波动拖累"——几何收益 ≈ 算术收益 − σ²/2。波动本身就在消耗复利，这与再平衡无关，是一切讨论的地基。
2. **Shannon's demon**：一个"典型路径永不赚钱"的资产，只要与现金各半并定期再平衡，就能每期稳定赚 +6.07%。再平衡赚的不是资产的钱，而是**波动结构**的钱。
3. **真实数据**：10 个 A 股行业等权组合，对比永不/月度/季度/年度四种再平衡频率（含双边万3成本）。你会看到红利**很小、有正有负**——和书上画的漂亮曲线很不一样。
4. **机制拆解**：用双资产精确公式 `D = Var(r1−r2)/8` 把"再平衡效应"从组合收益里剥出来，并逐年画柱状图，亲眼看到它在震荡年转正、趋势年转负。

学完后你应该能回答：**再平衡红利 = 用"低相关 + 高波动"换取的分散化溢价，它不是alpha，也可能被趋势市和手续费吃掉。**

## 1. 核心概念

### 1.1 几何 vs 算术收益：σ²/2 拖累公式

- **算术平均收益**：每期收益的简单平均，回答"平均一期赚多少"。
- **几何收益（复利增速）**：`期末净值^(1/期数) − 1`，回答"长期实际滚多快"。只有几何收益才是你口袋里的钱。

经典例子（`main.py` 第 1a 节实际打印）：

```
先 +50% 再 −33.33%：1.5 × 0.6667 = 1.0000 → 分文未赚
算术平均收益 = +8.3333%
几何收益     =  0.0000%
σ² = 17.3611%，σ²/2 = 8.6806%
验证：8.3333% − 8.6806% ≈ 0 ✓
```

每一期的"平均收益"都是正的 +8.33%，但长期复利是 0。差额就是**波动拖累**，一阶近似：

```
几何收益 ≈ 算术收益 − σ²/2
```

精确式（对数正态假设下）：`几何 = (1+μ)·e^(−σ²/2) − 1`。图01右图画出了两条曲线加模拟验证点：
算术年化固定 10% 时，σ≈45% 处几何收益已归零；σ=60% 时几何年化约 −8%。
模拟两资产（同算术年化 ≈7.3%~7.7%）：日σ=1.0% 的资产几何年化 **+6.47%**，日σ=2.5% 的资产 **−0.63%**——公式预测值与模拟值到小数点后两位完全吻合。

**这就是为什么"波动大"本身是成本**，也是分散化为什么有价值的数学根源。

### 1.2 Shannon's demon 直觉

构造（实际模拟，120 期、20000 条路径）：一个资产每期等概率 ×2 或 ×0.5。

- 每期对数收益期望 = (ln2 + ln0.5)/2 = 0 → **几何收益恰好为 0**，典型（中位数）路径永远原地踏步；
- 但算术期望因子 = 1.25/期——"期望收益"为正，全被极少数连开的幸运路径撑大（模拟中资产终值均值 3.9×10⁹，中位数却只有 1.00）。**中位数才是"你"**。

现在改成 50% 现金 + 50% 该资产、每期再平衡。组合每期因子 = 1 + 0.5×(f−1) ∈ {1.5, 0.75}，几何增长 = √(1.5×0.75) − 1 = **+6.07%/期**。模拟结果：120 期后组合终值中位数 **1172.6 倍**，而资产单独持有中位数 1.00 倍。

再平衡赚的钱从哪来？资产 ×2 时你在它上面的仓位只有一半，自动"落袋"了一半涨幅；资产 ×0.5 时你再平衡会把现金投进去一半，摊低了成本。**本质是把每期的极端波动，转换成了两个半幅波动的几何平均——而半幅波动的拖累只有 1/4（σ²/2 对 σ 是二次的）。** 现金没有收益不是关键，关键在于"仓位被强制反向调整"。

### 1.3 再平衡 = 反向高抛低吸

日频视角（`main.py` 第 258~287 行的回测循环）：再平衡日的换手 = 卖出涨多的（权重超过目标的）、买入跌多的（权重低于目标的）。每一步都是强制"高抛低吸"。它赚的是**资产间价格你追我赶的来回**（spread 的方差），不是资产本身的上涨。

### 1.4 为什么低相关 + 高波动才有红利

双资产 50/50 的精确分解（连续时间精确、日频高精度近似）：

```
逐日再平衡组合的对数增长 = 0.5·g1 + 0.5·g2 + D
再平衡溢价  D = Var(r1 − r2) / 8 ≥ 0
```

`r1 − r2` 是两资产的**收益差**。两资产同涨同跌（高相关）时收益差永远很小，D 趋近 0；负相关、高波动时收益差巨大，D 大。等σ时 `D = σ²(1−ρ)/4`：

- ρ=+0.9 → 红利只有 ρ=0 的约 1/10；
- ρ 固定时，红利随 σ² 增长——**高波动才有的红利**。

真实数据验证（半导体 vs 银行，相关系数 −0.08，年化波动 38.1%/17.1%）：实证 D̂ = **+2.29%/年**，理论 Var(r1−r2)/8 = **+2.31%/年**，几乎完全吻合。注意这个红利是**对数收益口径、且需逐日再平衡**才能拿满。

### 1.5 "再平衡红利不是免费午餐"：趋势市会拖后腿

`D ≥ 0` 的前提是"你会把涨多的卖掉、跌多的买回来"。如果市场单边趋势（强者恒强），再平衡等于**不断卖出赢家、买入输家**：

- 逐年贡献（10行业等权、月度再平衡 vs 买入持有，含成本）：2022 +1.00%、2023 −0.26%、2024 +0.03%、2025 +0.43%、2026* −1.27%，全样本累计 **−0.07%**——在这个 A 股样本里，月度再平衡相对买入持有**几乎没有净贡献**；
- Shannon's demon 里如果硬币"连续开出 ×2"，满仓者大赚，再平衡者只拿到一半。红利来自**均值回归式的波动**，趋势市里它是拖累。

同时别忘了：永不再平衡的组合会**漂移**——赢家权重越滚越大，组合波动和集中度悄悄上升（见"常见的坑"第 4 条）。所以再平衡的真实作用常常是"控制风险"而非"增厚收益"。

## 2. 数据与清洗（基期跳变）

- 10 个行业 CSV 起始日期不一（银行/证券 2018 起，电力 2021-12-29 起），取共同重叠期 **2021-12-29 ~ 2026-09-16，1119 个交易日**。
- 数据源存在**基期跳变毛刺**：指数基期切换导致单日 ±35% 以上的假跳动（本样本共同期内检出 **13 处**，如房地产开发 2024-08-05 +176%次日−64%、煤炭 2024-04 −50%/+103%、银行 2025-06/07 −50%/+104% 等）。
- 清洗规则：**单日 |收益| > 30% 视为跳变，该日收益置 0**（A 股有涨跌停约束，现实中不存在单日 ±30%）。该规则与全套课程（如 15_行业动量轮动）一致。若不做清洗，房地产开发等行业的年化波动会被虚增到 120% 以上，回测结论全错。
- 若 `data/cache` 缺失，脚本自动用 `np.random.default_rng(42)` 造 10 个合成行业兜底，并在所有图表标注"合成数据"。

## 6. 常见的坑

1. **把再平衡红利当成必然收益**。D = Var(r1−r2)/8 只是"对数收益口径、逐日再平衡"下的结构溢价，且前提是波动呈均值回归。趋势市里再平衡会持续卖出赢家（本课 2026* 贡献 −1.27%），Shannon 实验里连续掷出 ×2 时半仓者只拿到一半。红利是统计意义上的、薄的和有条件的。
2. **忽略再平衡成本与税费**。本课用双边万3的乐观假设，月度再平衡仍被吃掉 0.04%；换成含印花税/冲击成本的真实口径、或资产间换手更大的组合（如动量轮动），成本可以轻松吞掉全部红利。频率越高成本越高，收益却不一定越高。
3. **用短样本下"哪种频率最优"的结论**。本样本 4.7 年、四种频率差距 <1.2%/年，"季度最优"很可能只是这段历史的巧合。正确的做法是滚动窗口/多个市场/多次重抽样检验稳定性，而不是记住一个赢家频率。
4. **忘了漂移后组合风险悄悄变大**。永不再平衡的"赢家"，其年化波动和集中度会随行情漂移上升——即使期末净值不差，中途的风险暴露早已偏离你设定的等权目标。再平衡首先是**风险控制工具**（把风险拉回目标），其次才谈得上红利；只盯收益对比会误判它的价值。
5. （附加）**混淆两种比较口径**。理论公式 D 对应"逐日再平衡 vs 两腿加权几何增长"；实务对比的是"期初买入持有组合"，后者含终值平均化效应（半导体vs银行例中 g_mix−g_bh=+2.24% 略小于 D̂=+2.29%）。跨课引用数字时先对齐口径。

## 7. 延伸思考（练习）

1. **阈值再平衡**：把"每月/每季再平衡"改成"任一行业权重偏离目标 ±5 个百分点才触发"，用同一回测框架比较收益、换手与成本——它通常能用更少换手拿到相近的分散化效果。
2. **红利上限在哪里**：对 10 行业真实数据计算平均两两相关系数 ρ̄ 和平均波动 σ̄，代入 σ²(1−ρ)/4 估算"理论红利"，再与实测的逐年贡献对比，解释差异来自哪里（相关性时变、频率不足、成本、趋势）。
3. **把 Shannon 玩到底**：把 ×2/×0.5 改成 ×2/×0.6（几何收益变正），再平衡组合每期因子变为 {1.5, 0.8}，手算 √(1.5×0.8)−1 ≈ +9.5%/期；再用模拟验证"资产本身几何为正时，再平衡红利（D）反而变小还是变大"？想清楚为什么。
