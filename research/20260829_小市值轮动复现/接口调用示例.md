# 同花顺 iFinD 接口调用示例：入参与出参全解

本文件用**真实抓包**记录接口的完整调用过程：入参怎么构造、出参长什么样、返回过大的时候怎么处理。所有示例都是实际执行过的，原始响应文件在 `examples/` 目录。

## 一、接口本质：MCP over HTTP（JSON-RPC 2.0）

`call.py` / `call-node.js` 封装的底层协议是 **MCP over HTTP**，一次完整调用分 4 步：

```
① initialize 握手           → 换取 Mcp-Session-Id（会话ID，响应头里返回）
② notifications/initialized → 通知服务端初始化完成
③ tools/list                → 获取该服务可用工具清单（同时用于校验工具名合法性）
④ tools/call                → 真正的工具调用（携带上面的会话ID）
```

请求地址（以股票服务为例）：

```
POST https://api-mcp.51ifind.com:8643/ds-mcp-servers/hexin-ifind-ds-stock-mcp
```

## 二、入参：两层结构

### 业务层（你直接写的）

```python
call("stock", "search_stocks", {"query": "中小板指成分股中市值前3的股票"})
#      └─server_type      └─tool_name   └─params（就是业务入参）
```

### HTTP 层（call.py 内部实际发出的请求体）

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "search_stocks",
    "arguments": {
      "query": "中小板指成分股中市值前3的股票"
    }
  }
}
```

HTTP 请求头：

```
Content-Type: application/json
Accept: application/json, text/event-stream
Authorization: <mcp_config.json 里的 auth_token>
Mcp-Session-Id: <①握手时服务端返回的会话ID>
```

## 三、出参：三层嵌套结构

响应 JSON 一共包了三层，从外到内：

```
第1层 外层 HTTP 响应体:  {"jsonrpc":"2.0","id":3,"result":{"content":[{"type":"text","text":"..."}]}}
第2层 content[0].text:    一段 JSON 字符串 → {"code":1,"msg":"success","subCode":null,"subMsg":null,"data":"..."}
第3层 data（字符串）:      又一段 JSON 字符串 → {"answer":"markdown表格","dataTotalVolume":21,"selectedSecuritiesCount":3}
最终 answer:              markdown 表格，就是选股结果
```

关键字段说明：

| 字段 | 位置 | 含义 |
|---|---|---|
| `result.content[0].text` | 第2层 | 服务端业务响应（字符串形式） |
| `code` | 第2层 | 1=成功，非1=失败 |
| `selectedSecuritiesCount` | 第3层 | 符合条件总数 |
| `dataTotalVolume` | 第3层 | 返回数据总量（选股场景约等于总数） |
| `answer` | 第3层 | markdown 表格，含表头列名和每只股票的指标值 |

## 五、完整例子 2：大响应（53 只，分段保留）

**入参：**

```python
call("stock", "search_stocks", {"query": "中小板股票中总市值在10亿到30亿之间且单季度扣非净利润大于0且单季度营业收入大于1亿元的股票"})
```

**出参结构**和例 1 完全一样（三层嵌套），区别在 `selectedSecuritiesCount=53`，`answer` 里有 55 行表格（表头+分隔行+53 只股票）：

```
| 股票代码 | 股票简称 | 所属指数类 | 总市值[20260828] | 单季度.扣除非经常损益后的净利润[20260630] | 单季度.营业收入[20260630] |
|---|---|---|---|---|---|
| 002144.SZ | 宏达高科 | 中小综指;… | 1.98504318944E9 | 8591569.82 | 1.1671133495E8 |
| 002209.SZ | 达意隆   | …           | 2.7222949655E9 | 9.906883846E7 | 8.2733663547E8 |
| …（共53行，此处保留结构不全文贴出）…
| 002058.SZ | 紫竹高科 | 中小综指;… | 2.44292509396E9 | 8112540.79 | 1.9977455479E8 |
```

**大数据处理方式（三个事实 + 对策）：**

1. **单次返回行数有上限**（约 100–112 行）：53 只能完整返回，但 347 只全量那次就被截断了 → **对策：按市值分段查询**（10-30 / 30-40 / … / 80-100 亿 共 7 段），逐段核对"声明数量 == 表格行数"再合并去重。
2. **同条件重复调用结果有 ±1~2% 波动**：347 vs 352 的差异来自服务端，不是脚本问题 → 列表当"初筛池"用，别当精确结果。
3. **响应里的长字段**（所属指数类）会撑大文本 → 解析时只取需要的列。

完整原始文件：`examples/example2_big_response.json`（11.5KB，53 只全量）

## 五点五、结构化的接口长什么样：stock_highfreq_quotes

股票服务共 10 个工具，**9 个是自然语言入参（只有 `query` 字段），只有 1 个是纯结构化入参**——`stock_highfreq_quotes`（实时快照/高频行情）。

**入参（真实调用）：**

```python
call("stock", "stock_highfreq_quotes", {
    "symbols": "贵州茅台,宁德时代,招商银行",
    "indicators": "最新价,涨跌幅,成交量,成交额",
    "data_mode": "real_time"     # real_time=快照 / highfreq=高频序列(可配 interval 分钟)
})
```

**出参（原始，一字未改）**——注意和选股接口的不同：指标有中文→字段映射表，数据是二维数组：

```json
{
  "ok": true,
  "status_code": 200,
  "data": {
    "result": {
      "content": [
        {
          "type": "text",
          "text": "{\"code\":1,\"msg\":\"success\",\"data\":\"{\\\"dataVol\\\":\\\"12\\\",\\\"indicatorMap\\\":{\\\"最新价\\\":\\\"latest\\\",\\\"涨跌幅\\\":\\\"changeRatio\\\",\\\"成交量\\\":\\\"volume\\\",\\\"成交额\\\":\\\"amount\\\"},\\\"sympolMap\\\":{\\\"600519.SH\\\":\\\"贵州茅台\\\",\\\"600036.SH\\\":\\\"招商银行\\\",\\\"300750.SZ\\\":\\\"宁德时代\\\"},\\\"tables\\\":[[\\\"证券代码\\\",\\\"证券简称\\\",\\\"time\\\",\\\"最新价\\\",\\\"涨跌幅\\\",\\\"成交量\\\",\\\"成交额\\\"],[\\\"600519.SH\\\",\\\"贵州茅台\\\",\\\"2026-08-28 16:01:30\\\",\\\"1297.4\\\",\\\"0.39464520622147614\\\",\\\"16126\\\",\\\"2086008400\\\"],[\\\"300750.SZ\\\",\\\"宁德时代\\\",\\\"2026-08-28 16:00:30\\\",\\\"368.5\\\",\\\"-1.2064343163538873\\\",\\\"263769\\\",\\\"9706623300\\\"],[\\\"600036.SH\\\",\\\"招商银行\\\",\\\"2026-08-28 16:01:29\\\",\\\"39.35\\\",\\\"-0.5811015664476931\\\",\\\"481032\\\",\\\"1893074600\\\"]]}\"}"
        }
      ],
      "id": 3,
      "jsonrpc": "2.0"
    }
  }
}
```

**结构差异对比：**

| | 自然语言系（search_stocks 等 9 个） | 结构化（stock_highfreq_quotes） |
|---|---|---|
| 入参 | `{"query": "一句话"}` | `{"symbols": "...", "indicators": "...", "data_mode": "..."}` |
| 出参形态 | markdown 表格（列名带日期） | `tables` 二维数组 + 指标字段映射表 |
| 指标值 | 中文列名直接显示 | 中文指标映射成英文字段（涨跌幅→changeRatio） |
| 时间粒度 | 财报/日频为主 | 实时快照 / 分钟级高频 |

## 七、解析出参的固定套路

```python
import json

r = call("stock", "search_stocks", {"query": "..."})
text = r["data"]["result"]["content"][0]["text"]   # 第2层：JSON字符串
inner = json.loads(text)                            # → dict {code, msg, data}
biz = json.loads(inner["data"])                     # 第3层：JSON字符串
answer = biz["answer"]                              # markdown 表格
count = biz["selectedSecuritiesCount"]              # 总数
```
