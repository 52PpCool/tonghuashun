# 36 · 数据窥探检验：White's Reality Check —— "最好的参数"过得了统计这一关吗

> **一句话**：我从 26 组双均线参数里挑了样本内最好的那个，它显著吗？朴素 t 检验的读数不可信，因为它没算"26 选 1"；White (2000) 的 Reality Check 用 stationary bootstrap 把"挑最好"这一步搬进零假设，给出诚实的 p 值。
> 本课是[课 16（过拟合与交易成本）](../16_过拟合与交易成本/README.md)的统计学正规军续作：课 16 用"随机对照"让你**看见**数据窥探偏差，本课用 bootstrap 把它变成一个可以写进论文的 **p 值**。

---

## 一、这节课学什么

做完课 16 你已经知道：在 129 组参数里挑样本内最优，挑出来的成绩里掺着大量"运气"。但"运气"两个字说服不了审稿人、老板和你自己——你需要一个**检验**：把"我试了很多参数、只报告最好的那个"这一行为显式地放进零假设，然后问：

> **H0：这一族策略（26 组参数）里，最好的那个的真实超额收益 ≤ 0。**
> 观测到的"样本内最优成绩"，能不能和"纯靠运气在 26 个废物里挑出来的最好成绩"区分开？

学完本课你应能回答：

1. 为什么"对最优参数单独做 t 检验"得到的 p 值**原理上就是错的**——哪怕它碰巧很小？
2. White's Reality Check 的零假设分布怎么构造？为什么统计量是 **max** 而不是最优者自己？
3. stationary bootstrap 的"块"是什么？块长 l=5 在保留什么？
4. 怎么验证一套检验方法本身没坏掉（校准实验）？
5. 本课真实数据上，26 组参数的最优者朴素 p=0.641、RC p=0.952——统计上正式确认：**样本内最优无法与运气区分**（甚至低于纯运气冠军的典型水平）。

## 二、核心概念

### 1. 数据窥探偏差的形式化

你有 J 个策略（本课 J=26 组双均线参数），在第 t 日的**超额收益**（相对买入持有）为 `d_j,t`。你的研究流程是：

1. 在同一段样本上把 J 个策略各回测一遍；
2. 挑出样本内均值超额最大的 `j* = argmax_j d̄_j`；
3. 对 `j*` 做显著性检验，报告它的 p 值。

第 3 步的问题在于：`j*` 不是随机选定的，它是**用同一个样本挑出来的**。设第 j 个策略的真实日均超额为 μ_j，则 `d̄_j = μ_j + 噪声_j`。argmax 挑的是"μ + 噪声"最大的那个——它既可能是真最好的，也可能是**噪声最大的**。于是 `d̄_j*` 的分布不再是"某个固定策略的均值估计分布"，而是"26 个估计值的最大值的分布"——这个分布**系统性偏大**，对它做的 t 检验**系统性偏乐观**。这就是数据窥探偏差（data snooping bias），也叫选择偏差、多重比较问题的"只报冠军"变体。

### 2. 朴素 t 检验为何失效（以及它在本次真实运行中的读数）

朴素做法：对 `j*` 单独做 `H0: μ_j* = 0` 的 t 检验。本次真实运行（种子 42）：

- 样本内最优参数 **5/80**（快线 5 日 / 慢线 80 日），日均超额 **-0.672 bp**，年化 **-1.69%**；
- 朴素 t 检验：t = **-0.467**，p = **0.641**。

本次样本里最优者连朴素检验都不显著——这**不是**说朴素检验"这次侥幸没骗人"。要点是它的**读数不可信**：

- 朴素检验的 5% 保证只对"预先指定的、只测一次"的假设成立。一旦你是 26 选 1 之后才去检验，"p<0.05"的含义就变成了"26 个假设里至少一个假阳性"——即使 26 组参数**全是废物**，至少挖出一个 p<0.05 的概率是 `1 − 0.95^26 = 73.6%`（main.py 第 379 行打印）。
- 换句话说：朴素 p=0.641 这个数，既可能高估也可能"低估"最优者的真实 p……但只要行情配合一点（比如把样本换成就算盘打得更响的 2010–2019，见课 16：那段样本里最优参数年化 +4.46% 而买入持有 -0.64%），朴素检验完全可能交出一个 0.01~0.05 的"漂亮 p 值"——**而它依然是幻觉**。本课的校准实验（见第五节）用纯随机策略演示了这一点：26 条纯随机策略里有 2 条朴素 p<0.05（全噪声下期望约 1.3 条），随机最优者"随机05"的年化超额高达 **+2.52%**——比全部 26 个真实参数都好。**你如果碰巧挖到它，朴素检验不会救你。**

### 3. Reality Check 的零假设与 bootstrap 思想

White (2000) 的做法一句话：**把"从 26 个里挑最好"这一步原封不动地搬进零假设世界**。

- 检验统计量（观测值）：`obs = max_j d̄_j`——26 个策略的样本内均值超额的最大值（本课 = 5/80 的 -0.672 bp/日）。
- 零假设分布：构造一个"所有策略真实超额都 ≤ 0"的世界，在那个世界里**重复整个研究流程**（跑 26 个、取 max），看"最好的运气"能跑出什么成绩。重复 B=1000 次，得到 `boot_max` 的经验分布。
- p 值：`p_RC = (1 + #{boot_max_b ≥ obs}) / (B + 1)`——观测最优在"运气冠军分布"里被超过的比例。

关键技巧——**零假设世界怎么造**：把每列超额序列减去**它自己的样本均值**（`Xc = X − d̄`，main.py 第 152 行），就强行把每个策略的真实均值设成了 0（H0 成立）；再对中心化后的矩阵做 block bootstrap 重采样。这样每次重采样得到的 26 个均值都是"纯噪声下的均值估计"，取 max 就是"纯噪声世界里 26 选 1 的最好成绩"。

本次真实运行的结果：运气冠军零分布**均值 +3.25%/年、中位数 +3.16%/年**（全部在 0 右侧——即使所有策略都是废物，26 选 1 的样本内均值也"平均是正的"，这就是选择偏差的直观尺寸）；而现实观测 -1.69%/年，排在零分布的**第 4.8 百分位**——比 95.2% 的纯运气冠军还差。于是 **RC p = 0.952**，无法拒绝 H0。

### 4. stationary bootstrap 与块长 l

朴素 iid bootstrap 把 3804 个交易日**洗成乱序**，破坏了日收益间的短期依赖（自相关、波动聚集），得到的零分布方差不对。Politis & Romano (1994) 的 **stationary bootstrap** 改为"按块洗牌"：

- 把历史切成一串**随机长度的块**，每块长度服从 Geometric(p=1/l)，平均 l 天；块起点在样本中均匀随机，环形拼接回 T 天；
- 块内保持原有时间顺序 → 保留了约 l 天以内的短期依赖；块与块之间随机 → 保持平稳性（块长随机本身是让重采样过程平稳的数学要求）；
- 本课 l=5（约一周）：A股日收益的自相关主要集中在一周以内，l=5 是"保留短期依赖、又不让块太长"的折中。

块长的敏感性必须心里有数：l=1（退化为 iid）会低估零分布方差，p 值偏小（偏"显著"）；l 取到几百天则重采样退化（块太少），零分布过宽，p 值偏大。**规范做法是报告 l 在一个网格（如 1、5、20、60）上变化时 p 值的稳健性**——见"延伸思考"第 1 题。

### 5. 等价性假设：重采样"策略超额序列"而不是重跑策略（以及它的局限）

实现上有一个看似偷懒、实为标准的预处理：bootstrap 时**不**在重采样的价格路径上重跑双均线，而是**直接重采样各策略的超额收益序列 `d_j,t`**。等价性论证：策略持仓 `pos_t` 是历史的确定函数（给定参数，它是一条固定的历史序列），研究流程中"策略"这个对象在样本内已经完全凝固成序列 `d_j,t`；重采样日收益时同步重排这条序列，就等价于"在另一个平行世界里做同一次回测"。这正是 White (2000) 原文的做法——检验的数据单元就是业绩序列 `d_j,t` 本身。

但要知道它的**局限**（README 不写清楚就是骗人）：

1. 它回答的是"**样本内均值能否归因于运气**"，而不是"策略未来会不会失效"——持仓路径被冻结在历史里，重采样不产生新的持仓行为；
2. 它假设超额序列**平稳**且其时序依赖能被块重采样近似（极端行情结构变迁——比如课 16 展示的 2014–15 行情——会被块"搬"进别的年代，物理上不自洽，但这正是 bootstrap 的统计本意）；
3. H0 中心化用样本均值替代真实均值，是渐近近似（T=3804 时误差可忽略，短样本时要小心）；
4. 块环形拼接（wrap-around）在块首尾造成少量"虚构接缝"。

### 6. 与课 16、课 23 的关系：Bonferroni 粗糙在哪里

三件武器对付同一个敌人（多重检验），各有分工：

| 方法 | 回答的问题 | 机制 | 局限 |
|---|---|---|---|
| 课 16 随机对照 | "最优成绩和纯随机的最好成绩比，谁高？" | 经验 placebo：看真实最优落在随机最优分布的哪个分位 | 只给一个直觉数字，没有正式 p 值和检验框架 |
| Bonferroni（课 23） | "26 个检验里至少一个假阳性的概率控制在 5%？" | 每个检验用 α/J=0.05/26≈0.0019 的门槛 | 见下 |
| White's RC（本课） | "样本内最优能否与运气区分？" | bootstrap 模拟 max 统计量的完整零分布 | 依赖平稳性/块长等实现选择 |

**Bonferroni 粗糙在哪里**：

1. **浪费相关结构**。26 组双均线策略高度同涨同跌（超额收益两两相关平均 0.770、范围 0.463~0.957，main.py 第 358 行打印），"有效独立检验个数"远小于 26。Bonferroni 按最坏情况把门槛砍到 0.0019，**过度保守**——大量真信号也会被它拦下。RC 的 max 零分布**自动吸收相关结构**：本课真实运行里，真实参数族（彼此高度相关）的运气冠军零分布均值是 **+3.25%/年**，而随机策略族（两两相关均值只有 0.480，仅通过共同的市场敞口相关）是 **+5.08%/年**——族内越相关，"26 选 1"的运气溢价越小，RC 的门槛自动放得越宽。这是图 04 中间那幅图最该看的东西。
2. **答非所问**。Bonferroni 控制的是"任何一个是假阳性"的家族错误率，它不给你"最优者是否真好"的联合检验统计量；RC 直接检验 union 假设 `max_j μ_j ≤ 0`，正是研究者在做的那件事。

## 六、常见的坑

1. **只对最优策略做 bootstrap，忘了零分布要用 max**。对 `j*` 自己的中心化序列做 bootstrap，得到的是"单个策略均值的零分布"（图 03 蓝色，中心在 0）；RC 要的是"26 个里挑最好"的零分布（橙色，中心在 +3.25%）。两者差了整整一个选择偏差，p 值会从 0.95 错到完全不同的量级。
2. **块长拍脑袋还不做敏感性**。l=1 破坏短期依赖（本课若日收益有正自相关，零分布被低估、p 值偏小）；l 取几百天则重采样退化。l=5 是折中，写论文要报告 l 网格上的稳健性（练习 1）。
3. **B 太小，p 值不稳**。B=1000 时 p 的分辨率是 1/1001≈0.001，蒙特卡洛标准误约 √(p(1−p)/B)（p=0.05 时 ≈0.007）。若 p 落在 0.04~0.06 这种临界区，换一个 bootstrap 种子可能翻过 0.05 线——报 p 时把 B 和种子一起报。
4. **把"重排超额序列"当成了精确模拟**。重采样的是超额收益序列（等价性假设见第二节第 5 小节）：它冻结了持仓路径、假设平稳性。它回答"样本内成绩是不是运气"，**不回答"策略未来还有没有效"**——把 RC 当成对未来业绩的保证，是越界的解读。
5. **把 RC 显著当成"策略好"**。RC p<0.05 只说明"最优者的超额难以归因于运气"（H0: 全族真超额≤0 被拒绝），它对交易成本现实性、样本外衰减、过拟合强度一概不背书；反过来 RC 不显著也不证明策略无效，只说明**证据不足以排除运气解释**。本课 0.952 的正确读法是："拿不出不是运气的证据"。
6. **口径混淆：日均超额 ≠ CAGR 超额**。RC（和本课全部结论）检验的是日均超额的均值；低波动策略在这个口径下天然吃亏（买入持有的算术均值被 σ²/2 抬高约 1.9 pp/年，策略只被抬高约 0.9 pp）。本课 5/80 在 CAGR 口径只落后 0.71 pp/年，日均超额口径落后 1.69 pp/年。若你关心复利，可以改用对数超额 `ln(1+r_策略) − ln(1+r_基准)` 做 RC（练习 3）。

## 七、延伸思考

1. **块长敏感性**：把 `BLOCK_LEN` 换成 1、20、60 各跑一遍（只需改一个常量），记录 RC p 值。验证：l=1 时 p 值是否系统性偏小？你的结论（不显著）对块长稳健吗？
2. **放大选择强度**：把快线/慢线网格加密到 10×12（约 100 个有效组合，向量化代码无需改动），重跑 RC。观察运气冠军零分布右移多少——J 从 26 涨到 ~100，"最好的运气"涨了多少？这正是"参数试得越多，样本内最优越虚"的定量版本。
3. **换一个被检验的口径**：把超额收益换成对数超额 `np.log1p(策略收益) − np.log1p(基准收益)` 重跑全部流程。5/80 的 CAGR 差距只有 -0.71 pp/年，对数口径下 RC p 会变化多少？"检验什么口径"本身就是研究者的自由度之一。
4. **Hansen (2005) SPA 检验**：RC 对"混入大量废物策略"敏感（废物会抬高 max 零分布）。SPA 用 studentized 统计量 + 对劣质策略的重加权改进了这一点。试着读 Hansen (2005, *Review of Economics and Statistics*)，思考本课 26 个策略同质（全是双均线）时这个问题是否严重。
