# 伪十倍股对照画像：上一轮"十倍股画像"有区分度吗？（第38课·对照实验）

> 完成时间：2026-10-01。上一轮 [20261001_十倍股画像](../20261001_十倍股画像/) 给出了 88 只十倍股的五问画像；
> 本轮提出关键追问：**这些特征（硬科技行业/次新/小市值）到底是"十倍股的特征"，还是"所有大涨股都这样"？**
> 用同一数据管道跑一个对照组来检验——这是量化研究里"画像→区分度检验"的必修一步。

## 1. 对照组设计（本轮方法核心）

- **对照组**：同一次智能选股初筛 137 只（同一引擎、同一窗口、同一初筛选择）中，
  核验涨幅 ∈ **[500%, 1000%)** 的 **28 只**（来源：results_verified.csv，isTenX=0）。
- 两组唯一差异是核验涨幅档位，共享"通过初筛"的选择 → **条件对照组**。
- **诚实声明**：对照组不是"全体A股"，而是"初筛选出来的大涨股"。伪十倍股本身也是 +500% 以上的赢家；
  本轮回答的是"**初筛出来的大涨股内部，什么特征把十倍股和伪十倍股分开**"，不是"什么特征预测十倍股"。
- 数据管道与上一轮逐字相同：iFinD（上市日期/行业/2016-09-01市值/上市日市值）+ 新浪源日K（本轮分析未用到价格路径，仍全量留痕供后续轮次复用）。

## 2. 结果：三个特征全部有区分度（且过 Bonferroni）

| 假设 | 十倍股 n=88 | 伪十倍 n=28 | 效应量 | p 值 | Bonferroni(α=0.0167) |
|------|------------|-------------|--------|------|---------------------|
| **H1 行业**：电子/通信/机械 占比 | **63.6%** (56只) | 17.9% (5只) | OR=8.05 | **2.5e-05** | ✅ 显著 |
| **H2 上市批次**：窗口起点(2016-09-01)前已上市为"老股"，窗口内上市占比 | **85.2%** (75只) | 50.0% (14只) | OR=5.77 | **4.8e-04** | ✅ 显著 |
| **H3 起点市值**：中位数 | **26.4亿** | 46.7亿 | MW-U p=0.0014 | **0.0014** | ✅ 显著 |

**对照画像（伪十倍股长什么样）**：行业分散（基础化工4/电力设备4/汽车2/医药2/煤炭2/食品饮料2/建材2…），
50% 是老股（立讯精密、山西汾酒、牧原股份、中国神华…），起点市值中位 46.7亿。
一句话：**伪十倍股更像"白马价值股的十年"**（消费/周期龙头），十倍股更像"小市值硬科技的成长爆发"。

### H2 口径修正记录（2026-10-01 深度审查发现，规则5留痕）
- **问题**：`compare_analysis.py` 初版 H2 按 `上市年份≤2015` 判"老股"，而本管道的市值锚定用的是
  严格窗口口径（`listed_before_window`：上市日 < 2016-09-01）。十倍组有 2 只 2016 年内、
  窗口起点前上市的股票（**新易盛 2016-03-03、兆易创新 2016-08-18**）被错归为"窗口内上市"，
  导致同一假设两个口径数字打架（画像轮 README 85% vs 本轮 87.5%）；且图中标签
  "窗口内上市(2016-09后)"与实际所画口径不符。
- **核验**：对照组 2016 年上市的仅弘亚数控(2016-12-28) 1 只，两种口径下都是窗口内，故对照侧
  数字不受影响；重算仅涉及十倍组 77→75 的重分类。
- **修正**：H2 统一为严格窗口口径重跑 → 十倍组 75/88=**85.2%** vs 对照组 14/28=50%，
  **OR 7.0→5.77，p 9.1e-5→4.8e-4，仍过 Bonferroni(α=0.0167)，结论方向与显著性不变**。
  `comparison.json`、三面板图与 `compare_analysis.py` 已同步更新；旧值留痕于本节，不另删文件。

### H3 的重要细节（诚实报告）
- 连续检验（Mann-Whitney）显著 p=0.0014，但**二元化**（<50亿 vs ≥50亿）后 Fisher p=0.113 不显著：
  市值效应是**梯度**而非**阈值**——不存在"50亿以下就容易十倍"的切换点，只是十倍股整体更偏小。
- H3 若只报二元化结果会得出"市值无区分度"的错误结论；**二元化丢信息**是分类阈值选择的经典坑。

## 3. 解读与边界（必读）

1. **区分度 ≠ 预测力**。在"已通过初筛的大涨股"里有区分度，但"小市值+硬科技+次新"作为买入条件的
   基数成功率仍是未知数（分母缺失）。正确用法：作为**初筛后的排序特征**，而非独立选股条件。
2. **幸存者偏差在两组同向存在**，本轮对照把它部分抵消（都活到了 2026-08-31 窗口末），这是条件对照设计的收益。
3. **28 只对照组样本小**，OR 的置信区间宽（Fisher 精确检验已处理小样本，但效应量估计仍不精确）。
4. 行业是"事后分类"：2016 年时"通信光模块"未必被称作硬科技——**前视分类偏差**留作下一轮讨论题。
