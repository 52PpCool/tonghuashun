## 一、这节课学什么

股票是一维的（方向：涨/跌），期权是二维的（方向 + 时间 + 波动率）。这节课给你期权世界的"牛顿力学"——一套解析公式和五个"受力分析量"：

1. **Black-Scholes 公式**：欧式期权价格怎么算（自己动手实现，不用任何库的现成定价函数）；
2. **五个希腊字母**：期权的"仪表盘"，告诉你持仓到底在赌什么；
3. **蒙特卡洛定价**：用第 11 课学的 GBM 模拟重新定价，验证解析解（两条完全独立的路算出同一个数，这才是"学会"）；
4. **隐含波动率与波动率微笑**：从市场价格反推市场在想什么；
5. **Put-Call Parity**：期权市场最坚固的一条套利铁律。

学完你就能看懂期权行情软件上每一列的含义。

## 二、核心概念

### 2.1 B-S 公式与每个符号

对不付红利的标的，欧式看涨期权价格：

```
C = S0·N(d1) - K·e^(-rT)·N(d2)
P = K·e^(-rT)·N(-d2) - S0·N(-d1)
d1 = [ln(S0/K) + (r + σ²/2)·T] / (σ·√T)，  d2 = d1 - σ·√T
```

| 符号 | 含义 | 本课取值 |
|---|---|---|
| S0 | 标的现价 | 1266.98 元（茅台收盘价） |
| K | 执行价（strike），到期你可以用这个价格买（call）/卖（put） | K = S0（平值） |
| r | 无风险利率（年化、连续复利），相当于"钱的租金" | 2% |
| T | 到期期限，**以年为单位** | 0.25 年（约 3 个月） |
| σ | 标的年化波动率 = 日对数收益率标准差 × √252 | 24.13%（茅台过去 60 日） |
| N(·) | 标准正态分布的累积分布函数（`scipy.stats.norm.cdf`） | — |
| φ(·) | 标准正态密度（`norm.pdf`，希腊字母要用） | — |
| e^(-rT) | 贴现因子：把到期时的 K 折现到今天 | 0.99501 |

读公式的直觉：`C = "可能拿到股票"的期望现值 − "可能付出现金"的期望现值`。N(d2) 近似是"风险中性世界里到期股价高于 K 的概率"。

**平值 call = 64.0158 元**（内在价值 0.00 + 时间价值 64.0158），平值 put = 57.6967 元。

### 2.2 为什么期权价格与"路径"无关，只与终值分布有关

欧式期权到期损益是 `max(S_T − K, 0)`——**只看到期那天 S_T 落在哪，中间怎么走完全不重要**。所以定价只需要 S_T 的概率分布，不需要路径。B-S 用对数正态分布解析地积分了这个期望；蒙特卡洛则是直接抽 10 万个 S_T 求平均（第 3 节）。两者殊途同归。

（注意"欧式"三个字：美式期权可以提前行权，某些情形提前行权更优，路径与持有策略就有关系了，B-S 公式不再适用。）

### 2.3 五个希腊字母的风险直觉

每个字母回答一个问题（平值处的真实数值见"输出怎么读"）：

| 字母 | 问题 | 直觉 |
|---|---|---|
| **Delta** | 股价动 1 元，期权动多少？ | 方向敞口/对冲比率。call 的 Delta∈(0,1)：0.54 意味着"半只股票" |
| **Gamma** | 股价动 1 元，Delta 动多少？ | 方向敞口的变化速度。**平值 + 短到期时最大**——股价一晃，对冲比例就得重调（凸性的来源） |
| **Vega** | 波动率升 1 个百分点，期权动多少？ | 买期权 = 做多波动率（怕波动率降）；卖期权 = 做空波动率 |
| **Theta** | 每过一天，期权"自然蒸发"多少？ | 时间磨损。买方每天交房租，卖方每天收房租 |
| **Rho** | 利率升 1 个百分点，期权动多少？ | 通常最小，高利率环境下才显眼。call 为正、put 为负 |

记忆钩子：**Delta 方向、Gamma 加速度、Vega 怕安静、Theta 怕等待、Rho 怕央行**。
平值附近是所有"曲率类"希腊字母（Gamma/Vega/Theta）的重灾区——这是图 02 五条曲线都在 K=S0 处达到极值的原因。

### 2.4 隐含波动率：市场对未来的定价

历史波动率是"过去 60 天实际晃了多少"；**隐含波动率（IV）是"把市场价格代回 B-S 公式反解出来的 σ"——它包含了市场对未来波动率的全部共识**，还掺着供求与恐慌溢价。期权交易员根本不谈价格，只谈"这个月 IV 多少个 vol"。IV 高 = 期权贵 = 市场紧张。

**波动率微笑**：把同一到期日、不同执行价的 IV 画成曲线，真实市场不是一条水平线，而是两边翘起的"微笑"（A股还常见左翼更高的"偏斜"）。微笑的存在本身，就是市场对"B-S 对数正态假设"的否定——真实收益率有肥尾，极端行情比正态假设更常见（呼应点子 11 蒙特卡洛里看到的尾部）。

## 三、Put-Call Parity 的套利直觉

同一 K、同一 T 的欧式 call/put 必须满足：

```
C − P = S0 − K·e^(−rT)
```

套利直觉：两条路买到的东西一模一样——
- **组合 A**：买 1 张 call + 卖 1 张 put。到期无论如何都恰好以 K 买入一股股票（涨了行权 call，跌了被行权 put）；
- **组合 B**：今天借 K·e^(−rT) 元买 1 股股票，到期正好还 K。

到期现金流完全相同 → 今天价格必须相等，否则"买便宜的那个、卖贵的那个"，**零风险白赚差价**。本课数值验证：C − P = 6.3190890150 元，S0 − K·e^(−rT) = 6.3190890150 元，差 1.137e-13（纯浮点噪声）。parity 对美式期权只是不等式（提前行权会打破它）。

## 七、常见的坑

1. **波动率 24 写成 24 还是 0.24**：B-S 公式里的 σ 是**小数**（24.13% 要写 0.2413）。写成 24，d1 会大到离谱，期权价格直接等于股票价格；两种单位混用时 Vega 计算最容易翻车。本课惯例：公式里一律小数，展示时才乘 100。
2. **T 用日历天还是交易日**：年化波动率按 252 个交易日算，T 却按**日历天/365**（或年的小数）计。3 个月是 T=0.25（日历口径），不是 63/252。两套口径混用的后果：期权价格错、Theta 错，且错得并不对称。跟着市场的到期日历走：T = (到期日 − 今天)/365。
3. **美式当欧式定价**：B-S 只对**欧式**期权严格成立。A股场内ETF期权、美股个股期权都是**美式**，直接套 B-S 会低估（put 尤其明显，深实值 put 提前行权锁定利息是有价值的）。美式要用二叉树/PSOR，别拿 B-S 硬算。另外分红也会改变公式（要减掉红利现值）。
4. **r=0 的情形**：利率为零不是"公式报错"而是特例要检查——e^(−rT)=1，parity 退化为 C − P = S0 − K，call 的 Rho=0。写代码时先用 r=0 跑一遍 sanity check（C ≥ max(S0−K,0) 恒成立），能抓住一半的符号错误。顺带一提：随着 r→0，平值 call 与 put 价格只差一个贴现项，图 02 的 Delta 曲线在 r=0 时平值处恰好对称。
5. （附送）**蒙特卡洛给欧式定价可以只模拟终值**——别傻乎乎模拟整条路径再只取最后一点，那是给亚式/障碍期权（路径依赖）才需要的。本课 10 万路径 0.1 秒，模拟路径则要 100 倍内存。

## 八、延伸思考（练习）

1. **把 T 缩到 1 周（T=1/52）**：重跑后看平值 Gamma、Theta 各变化多少倍？验证"平值 Gamma ∝ 1/√T、平值 Theta ∝ 1/√T"——短期平值期权是 Gamma/Theta 交换最激烈的地方，这也是 0DTE（零日期权）疯狂的原因。
2. **用对偶变量给深度虚值（K=1.3·S0）call 定价**：分别用普通 MC 与对偶变量 MC 各跑 10 万路径，比较两者的标准误——你应该能看到对偶变量这次真的把 SE 砍掉一大截（为什么？提示：虚值 payoff 大部分样本是 0，配对后两个一半要么都为 0 要么互补）。
3. **造一条"偏斜"而不是对称微笑**：把 `smile_sigma_true` 改成 σ(K) = 0.25 + 1.5·[ln(K/S0)]² − 0.15·ln(K/S0)（左翼更高），重跑图 04。思考：如果这是真实市场，说明市场认为暴跌和暴涨哪个更极端？这与你从茅台历史收益率分布（第 11 课的肥尾图）里看到的偏度一致吗？
4. （进阶）**验证 Delta 对冲**：模拟 S_T 的同时模拟 Δ=(S_T−S0) 期间"持有 Delta 份股票"的盈亏，检查 Delta 对冲组合的方差是否远小于裸买期权——这就是 B-S 推导背后"无风险对冲"思想的数值版。
