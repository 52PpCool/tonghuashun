## 1. 这节课学什么

1. **把"策略"当"资产"来配钱**。前 33 课里，资产配置（课09/10/26）配的是股票、行业这些"标的"；
   本课配的是"策略"——每条策略先换算成一个自带现金利息、自带交易成本的**日净收益序列**，
   再决定给每条策略分多少钱。这是多策略私募/自营账户的真实组织方式。
2. **四条子策略的忠实复刻**（都用缓存真实数据、规则简单明确、双边成本、日频净值）：
   - **S1 双均线**（课02）：上证指数 SMA20/60，金叉持有、死叉空仓，信号收盘生成、次日生效；
   - **S2 海龟简化**（课03）：茅台 20 日唐奇安突破入场 / 10 日反向离场 / 2N 止损（ATR20 为 N），
     不做金字塔加仓、全仓进出；
   - **S3 行业轮动**（课15/27）：10 个行业板块 60 日动量 Top3 等权、月末调仓，从板块数据共同重叠期起；
   - **S4 波动率目标择时**（课28 仓位学的近亲）：上证+茅台各设半仓，各按 10% 年化目标波动缩放，
     日频调仓——`w_i = 0.5 × min(1, 10%/σ_i(20日年化))`，波动超过目标就减仓、最多半仓（不加杠杆）。
3. **本课灵魂：策略相关性**。四策略日收益相关系数矩阵 + "组合夏普能否超过最佳单策略"的
   实际数字验证（本样本**证伪**了，原因见下文——这比验证成功更有教育意义）。
4. **四种配钱方式**：等权 / 逆波动率 / 最小方差（cvxpy，滚动 252 日） / 风险平价（逆方差代理），
   月度再平衡，**含子策略之间调仓成本单边万3**。
5. **回撤拼图**：组合最大回撤期间各子策略贡献分解（谁在跌），以及"危机中相关性是否上升"的实测。

## 2. 核心概念

### 2.1 策略层面分散化 ≠ 资产层面分散化
资产层面分散化（课09-10）分散的是**标的之间的特异风险**；策略层面分散化分散的是**信号来源**：
趋势（S1/S2）、截面动量（S3）、波动率（S4）的仓位方向可以互相打架——同一时刻海龟在做多茅台、
双均线可能正空仓、轮动可能押在地产上。理论上策略相关性比资产相关性更低、分散化效果更好；
**但前提是每条策略自身有正期望**——本课实测会发现这个前提在 2022-2026 的 A 股样本里并不成立。

### 2.2 "低相关 + 正期望"的加权效应公式直觉
若 N 条策略夏普同为 SR、两两相关均为 ρ，等权组合的夏普约为

```
SR_组合 ≈ SR × √( N / (1 + (N-1)·ρ) )
```

N=4、ρ=0.437（本课实测均值）时理论提升 √(4/(1+3×0.437)) ≈ **1.32 倍**；ρ→0 时可达 2 倍。
注意两个前提：①各策略夏普为**正**（公式放大幅度、不能把负期望变正——负期望策略合在一起
只会更均匀地亏）；②各策略夏普**大体相当**（否则最差者拖累组合）。本样本四策略夏普
（-0.32/-0.08/-0.26/-0.50）两个前提都不满足，所以实测等权组合夏普 -0.353 反而低于最佳单策略
-0.080——**证伪并如实归因**，这本身就是这节课要教给你的判断力。

### 2.3 逆波动率加权为什么常用
`w_i ∝ 1/σ_i`：给波动小的策略多分钱，让每条策略对组合风险的贡献大致拉平。它只需要波动率
（协方差矩阵的对角线），**不需要均值**——而均值恰恰是估计中最不可靠的量（课09 的教训）。
它极端稳健：不会算出负权重、不会把 40% 权重押给一个"估计年化 +50%"的幻觉。代价是它对
**相关性**视而不见（本课实测：逆波动率把 15% 权重给了波动最大、也最拖累的 S3）。
介于等权（全不看）和最小方差（全看协方差、不看均值）之间，是实践中的默认起点。

### 2.4 子账户现金假设
每个子账户中**未投资的仓位按无风险利率 2% 年化计息**（日利率 2%/252），相当于放在货币基金/
逆回购里。这是把"策略"变成"可配置资产"的关键假设：S1 死叉期间、S2 离场期间、S4 减仓下来的
部分都在"生息"，否则空仓期收益为 0，各策略的夏普会被系统性低估，组合权重也会失真。
简化之处：真实券商闲资利率更低、且现金管理也有少量摩擦，本课统一记 2%。

### 2.5 策略容量与独立性
- **独立性**：S1/S3/S4 都以上证系资产为锚，S2 是唯一的"个股+止损"来源；四条策略里有三条
  的仓位都受同一个市场 β 驱动，所以实测平均两两相关 0.437——**A股策略想做到 0.2 以下，
  必须引入跨市场/跨资产/做空机制**，仅靠"A股+规则不同"不够。
- **容量**：S3 押 3 个行业板块、S2 押一只股票，容量小、冲击成本敏感；本课用固定万3 成本近似，
  真实放大资金后 S2/S3 的成本拖累会非线性上升（课30 的主题）。

### 2.6 "策略相关性在危机中上升"
分散化最尴尬的时刻是你最需要它的时刻。本课做了三处实测（详见第 5 节数字）：
慢熊阴跌的回撤窗口内相关**没有**上升（0.398 vs 全样本 0.437），但 924 暴涨后的急跌段
（2024-10-09 ~ 2025-01-03）平均两两相关飙到 **0.670**（比全样本高 53%）——
**快跌是系统性的，什么信号都挡不住**；分散化防的是"某条策略独自犯蠢"，防不了"整个市场一起跌"。

### 5.6 如实结论
1. **策略组合值不值得？** 本样本分两层答：收益维度**不值得**（四策略全负期望，任何加权都救不回
   夏普）；风险维度**值得**——等权把 -43% 的单策略灾难稀释成 -18%，最小方差进一步压到 -13.7%
   且年化转正。组合的日常意义是**让任何一条策略犯蠢时不至于毁掉账户**。
2. **成本拖累多少？** 组合层仅 0.014%~0.068%/年（月度再平衡）；真正的成本大头藏在各子策略内部
   （S3 年均换手高，含成本后比课15 无成本版年化差约 0.8pp）。
3. **哪条策略贡献最大？** 风险上 S3 是最大的负担（波动 20.6%、回撤窗贡献 -11.6pp、
   被最小方差清仓）；收益上 S2 海龟是唯一的正贡献者（回撤窗 +1.6pp）且全历史夏普最高
   （0.759）——**趋势策略是组合里最稀缺的"另类"信号**，它和其余三条相关性最低（0.23/0.28）。

## 6. 常见的坑

1. **子策略共用同一现金池 → 隐性杠杆**。若四条策略"共用一个账户的钱"各自下单（而不是各按
   1/4 名义本金独立核算），S4 减仓腾出的现金会被 S2 的新突破单借走——实际杠杆悄悄超过 1 倍，
   回测里看不出来，实盘爆保证金才暴露。本课的"每策略一份独立子账户"就是把名义本金切干净。
2. **不同起始日期直接拼接**。四条策略起点差 12 年，若不 dropna 对齐直接 concat，
   pandas 会用 NaN 污染前段或悄悄截短样本；更隐蔽的是"各自回测各自的时间段再拼净值"——
   那是四张不同考卷拼成一张成绩单（本课共同区间只剩 4.7 年，这个代价必须写在脸上）。
3. **忽略子策略之间的调仓成本**。月度再平衡不是免费的：本课最小方差年均换手 2.28，
   成本 0.068%/年看着小，但若改成日频调仓或纳入更贵的"策略切换"（申购赎回费/停牌），
   拖累会放大一个数量级。凡是引擎里没有成本项的"组合增强"，先怀疑是没付路费。
4. **把历史相关当稳定**。全样本 ρ=0.437，最深 60 日危机段 0.670、924 事件窗 0.468——
   相关性不是一个数，是一条随行情呼吸的曲线。用全样本相关做的风险平价/最小方差，
   在下一次危机里的真实分散效果一定比回测显示的差（本课 MinVar 的"成功"部分来自它
   干脆清仓了高波动的 S3，而不是预测准了相关结构）。
5. **过拟合权重**。本课四种加权只用波动/协方差、不碰均值，就是这个原因：一旦允许优化器
   看样本内均值，它会把权重押给"回测年化最高"的策略（大概率是运气最好的那条）。
   想验证：把估计窗从 252 改成 120 或 504，看权重和排名是否稳定——不稳定的就是噪声。
6. **基期跳变毛刺的正确清洗姿势**。板块指数常被数据源重置基期：正确做法是**只把该日收益率
   置 0、价位不动**（本课与课15同款）；若把价位"改回前收盘"，跳变次日的收益会被假分母
   放大出新的毛刺（本次开发实测：银行板块被造出 +103% 的假单日收益，S3 波动从 20% 虚增到 36%）。

## 7. 延伸思考（练习）

1. **把估计窗变成实验**：把 `EST_WINDOW=252` 分别改成 126 和 504，重跑并回答——
   最小方差还清仓 S3 吗？组合夏普排名变了吗？用这个实验体会"协方差估计的不稳定性"。
2. **加入第五条策略**：用课04 的网格策略（震荡市收割机）作为 S5 加入面板——
   它与 S1-S4 的相关性应该更低（吃波动率而非方向）。观察等权组合夏普和危机段相关性如何变化。
3. **危机中的动态降相关**：写一个规则——当组合 20 日已实现波动超过其 252 日 80% 分位时，
   把 S3 的权重强制减半、多出的份额给现金。重跑后对比：最深 60 日危机段的损失和相关系数
   变化了多少？这种"危机中降风险"规则改善的是收益还是回撤？
