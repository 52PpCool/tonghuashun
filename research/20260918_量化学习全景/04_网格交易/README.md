# 04 网格交易 —— 用真实数据验证"网格赚波动钱、亏趋势钱"

> 一句话：把"高抛低吸"机械化成一张价格网格，在上证指数近10年真实日K上跑回测，
> 逐年对照网格与买入持有，亲眼看看这句行话哪一半对、哪一半要打折。

- 数据：`../data/cache/index_000001_上证指数.csv`（真实日K，2010起；本课取**2016-09-19 ~ 2026-09-17，共2427个交易日**）
- 环境：`.venv/bin/python`（numpy/pandas/matplotlib），单文件 `main.py`，运行约2秒

## 1. 这节课学什么

1. **网格交易的本质**：把"高抛低吸"从主观判断变成机械规则——事先画好一排价格格线，
   跌破一条买一份、涨破一条卖一份，不预测方向，只收割"来回震荡"。
2. **一套最小的网格回测引擎**：格线数组 → 持仓格数状态 → 逐日成交判断，40行核心代码。
3. **用数据检验行话**："网格赚波动钱、亏趋势钱"——这句话在我们的真实回测里**方向完全正确，
   但要加上时间维度的精确表述**（见第5节：跌的年份网格全赢、涨的年份网格全输）。
4. **参数敏感性与成本意识**：格数取10/20/40结果几乎一样（本例），以及612笔交易到底交了多少学费。

## 2. 核心概念

### 2.1 网格 = 高抛低吸的机械化

人工高抛低吸的死穴是"情绪"：跌了不敢买（怕继续跌），涨了舍不得卖（怕卖飞）。
网格把这些决策**提前写死**：

- 划定价格区间 `[P_low, P_high]`，等分成 N 格，得到 N+1 条格线；
- 每格配一份资金（本课：总资金的 1/(N+1)）；
- 价格**下穿**某条格线 → 买入一份；**上穿** → 卖出一份；
- 价格越低，持仓格数越多（低多高少），所以永远**不满仓也不满空**。

它赚的是"同一条格线附近一买一卖的价差"：跌下去买的那份，涨回来卖掉，每来回落赚约一格。
代价是：单边行情里它永远"半仓踏空"或"越跌越买接飞刀"。

### 2.2 为什么用等比网格（而不是等差）

**等差网格**：每格价差固定，比如每100点一格。但100点在2500点是4%，在4000点只有2.5%——
同样是"一格"，低位的格子风险/收益是高位的一倍多，网格疏密在数学上就不均匀。

**等比网格**：格线按 `L_k = P_low · (P_high/P_low)^(k/N)` 划分，即**在对数价格上等距**，
每一格的涨跌幅相同（本例每格 +2.75%）。金融价格波动是"乘性"的（涨跌幅与价位高低大体无关），
等比网格让每一格承担相同的波动、赚相同的比例收益，低位不会"一格太贵"，高位不会"一格太密"。
实现上只有一行：`log_step = ln(P_high/P_low) / N`（main.py 第99行）。

### 2.3 直觉公式：网格收益 ≈ 震荡收益 + 择时损耗

- 买入持有只赚**首尾差价**（趋势）：起点3026点 → 终点3876点，10年+28.1%。
- 网格额外赚一份**路径收益**：价格在区间里来回穿越格线，每来回落一份钱。
  上证这10年宽幅震荡（2018、2022~2024两轮深跌又拉回），路径收益为正，
  所以网格10年+37.1% > 买入持有+28.1%。
- 但在单边行情里路径收益贡献很少，而"低多高少"的仓位结构变成拖累：
  牛市里一路卖、仓位越来越轻 → **少赚**；熊市里一路买、越买越重 → **照亏**（只是亏得少些）。
  这就是"赚波动钱、亏趋势钱"的准确含义：**震荡是网格的朋友，趋势是网格的敌人**。

## 3. 代码怎么读（main.py 关键行号）

| `run_buy_hold()` | 第143行 | 基准：期初全仓买入不再动 |

读代码建议按"状态机"理解：**每天只问一句"今天价格落在第几格？"**，
格数比昨天低（价格涨了）就减仓，比昨天高（价格跌了）就加仓，变化几格就成交几份。没有预测，只有反应。

网格不是印钞机，它是一种"把收益曲线磨平"的工具：用牛市里的超额收益，换熊市里的安全垫。

## 6. 常见的坑

1. **区间设太窄被击穿**：网格只在 `[P_low, P_high]` 内工作。价格跌破下沿后，该买的都买完了
   （仓位顶在N/(N+1)≈95%），继续下跌只能硬扛；涨破上沿后只剩1格底仓，牛市与你无关。
   本课区间取"近10年最低/最高收盘价"才算安全，实盘很多人按近1年高低点设网，2024年9月底
   一周暴涨就把半张网击穿了。区间应该"宽而不密"，并定期上移/重建。
2. **单边牛市跑输的焦虑**：看5.2节，2025年网格少赚8.8pp，2019~2021连续三年跑输。
   网格持有人最大的敌人不是熊市而是牛市——每天看着满仓的朋友净值飞奔，自己半仓"高抛"。
   如果你不能接受"牛市注定跑输"，就不要用网格，或者只用小仓位做底仓增强。
3. **把网格当无风险策略**：熊市里网格一路买、仓位一路加到95%，2018年照样-15.6%。
   网格只是"仓位管理规则"，**不改变标的本身的方向风险**；标的腰斩，网格只是腰斩得慢一点。
   （本课开发中还踩过一个真bug并已修复、如实记录：初版把目标仓位写反成"价低仓轻"，
   变成追涨杀跌，震荡情景年化-21%、回撤51%——方向反了，网格就是绞肉机，记住"低多高少"。）
4. **忘记现金也有机会成本**：网格平均仓位只有57.5%，即约42.5%的资金常年闲置。
   本回测现金收益记为0；实盘这笔钱至少该放货基/逆回购（年化1.5%~2%），10年能额外贡献6%以上；
   反过来说，若无息闲置，"网格跑赢买入持有"的结论会打折扣。
5. **日频回测的撮合近似**：本课用收盘价判断穿格并以收盘价成交；实盘网格是盘中触价挂单，
   成交价与日内路径有关。加上滑点与"隔夜跳空一次穿多格"的情况，实盘结果会与回测有偏差。

## 7. 延伸思考（练习）

1. **成本压力测试**：把 `COST_RATE` 从万3改到万10、万25（含滑点），看网格年化还剩多少；
   再算格数N=40时的高费率版本——找出"网格收益被手续费吃光"的临界费率。
2. **动态区间**：把固定区间 `[10年低点, 10年高点]` 改成滚动窗口（如近250日高低点）每年重建网格，
   重跑分年度表，看2024~2025单边段的表现是否改善，还是引入了新的问题。
3. **网格+趋势过滤**：加一条规则——仅当价格高于200日均线时才执行"卖出格"（或干脆停用网格），
   能否把2025年的-8.8pp追回来？付出的是什么？（提示：这与本套课程第02课的双均线是同一个思想。）
