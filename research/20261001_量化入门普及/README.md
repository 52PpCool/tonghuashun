## 1. 量化到底是什么

**一句话定义**：把"买什么、买多少、什么时候卖"写成明确的数据规则或模型，用程序执行和验证，而不是临场拍脑袋。

三个常见误解先破掉：

1. **量化 ≠ 高频**。高频只是量化的一个极端分支（持仓秒级）。按天、按周调仓的选股策略同样是量化，而且更适合个人。
2. **量化 ≠ 必赚**。量化只是让决策变得**可验证、可复盘、可复制**——赚不赚钱另说，但它至少能让你精确知道自己是错在哪。
3. **量化 ≠ 神秘数学**。双均线策略两条线，也是量化。复杂度不是门票，纪律才是。

一条光谱：主观交易 → 主观+量化辅助 → 规则化量化 → 全自动 → 高频。个人玩家的合理位置在中间三档。

## 2. 一个量化策略的一生（流水线）

```
想法 → 数据 → 信号/因子 → 组合构建 → 回测 → 样本外/纸面 → 小资金实盘 → 监控迭代
```

关键认知：**错误越靠前越致命**。数据错了，后面全是在精确地计算垃圾；回测有未来函数，实盘就是给你上课。每个环节展开如下。

## 3. 数据：一切的地基

- **复权（前复权/后复权）**：分红送股会在K线上留下假跳空，不复权会把"分红"误读成"暴跌"。必须复权，且要搞清用哪种口径。
  - 本工作区实例（2026-09-05 十倍股研究）：智能选股引擎的"前复权区间涨幅"列计算异常，高分红股被严重虚增——贵州茅台被标 6913%，实际只有 +417%。**同一指标换个口径，结论天差地别。**
- **幸存者偏差（survivorship bias）**：只用"今天还活着"的股票回测，等于开着天眼考试——退市股（往往是跌得最惨的）被悄悄剔除了。
  - 本工作区实例（第41课）：PIT 股票池里，2016 年的池子被退市吃掉 246 只、占 8.4%。不做 PIT，这 8.4% 的亏损就从回测里消失了。
- **PIT（Point-in-Time，时点数据）**：回测某一天，只能用"那一天当时能拿到"的数据，不能用事后修正过的财报、事后才知道的成分股调整。
- **能看见价格 ≠ 能成交**：停牌、一字涨跌停的日子里，数据里有价格，但你买不进、卖不出。这不是细节，见第 5 节。

## 4. 信号与因子

- **因子**：一个可计算的数值，用来解释或预测股票之间收益的差异。例如：小市值、低波动、高ROE、20日涨幅（动量）、市盈率（价值）。
- **检验因子是否有区分度的标准工具**：IC（因子值与下期收益的相关性）、分层回测（按因子值分10组，看收益是否单调）。
- **重要教训（第42课）**：十倍股画像因子在统计上区分度极强（对照组检验全过 Bonferroni），但拿去做分层组合，Spearman ρ=0，逆着画像买和顺着画像买收益差不多。**"能区分"和"能赚钱"是两回事**，中间隔着成本、时点、组合权重。
- **因子 ≠ 策略**：因子是原料，策略=因子+组合规则+调仓频率+风控。

## 5. 回测：最容易自欺的环节

回测的默认假设应该是"**它是错的，除非证明它没错**"。四大杀手：

1. **未来函数（look-ahead bias）**：用了当时不可能知道的信息。最典型的：用当天收盘价做信号、当天开盘价成交（收盘价在开盘时还没发生！）。
2. **过拟合（overfitting）**：参数贴合了历史噪音而不是规律。警报信号：参数稍微一动结果剧变；指标好到离谱；规则复杂到讲不清。
3. **成本**：佣金、印花税（卖出 0.05%）、滑点、冲击成本。高换手策略对成本极其敏感——年换手 100 倍，光摩擦就吃掉好几个点。
4. **成交约束（A股特色）**：T+1（今天买明天才能卖）、涨跌停（一字板买不进）、停牌。
   - 本工作区实例（第39课）：事件驱动引擎把"连板拒单"实现进去后，一个回测年化 61% 的策略，纸面收益直接不可实现——涨停板上你根本买不进去，能买进去的日子往往是策略信号已经衰减的日子。

**评价指标速查**：

| 指标 | 含义 | 小白要点 |
|------|------|---------|
| 年化收益 | 折算成每年的收益率 | 单看它毫无意义 |
| 最大回撤 | 峰值到谷底的最大跌幅 | 决定你能不能拿得住；也要看回撤持续多久 |
| 夏普比率 | 收益/波动 | 一般 >1 尚可，>2 要警惕 |
| 卡玛比率 | 收益/最大回撤 | 比夏普更贴近体感 |
| 胜率 × 盈亏比 | 赢的频率 × 赢一次赚的与输一次亏的比 | 二者乘起来才是期望，只吹胜率的都是耍流氓 |
| 换手率 | 买卖频率 | 直接决定成本敏感度 |
| 容量 | 策略能管多少钱 | 个人一般不用操心，但小市值策略天然容量小 |

**防过拟合的手段**：样本内/样本外切分（留 20-30% 数据永不参与调参）、walk-forward 滚动验证、参数敏感性扫描（参数 ±20% 看策略死不死）、第36课的 Reality Check（数据窥探检验）、第32课的 Purged CV + Embargo。

## 6. 组合与风控（简版）

- 仓位：等权是最简单也最难被打败的起点；进阶有波动率倒数、风险平价。
- 分散：单票集中度、行业暴露都要设上限。
- 风控线（如回撤 20% 减半仓）必须写在代码里，不能写在心里。
- 市场中性/对冲（股指期货贴水成本）、期权这些，小白阶段先不碰，知道存在即可。

## 7. 实盘前的台阶：纸面交易（模拟盘）

纸面交易检验的是**工程实现**（信号计算对不对、订单逻辑有没有bug、数据延迟），不是 alpha 有没有效。第40课就是干这个的：SQLite 状态机+幂等+对账，86天回填揪出了两个真 bug（拒单不落库导致重复成交、浮点往返出现 0 股）。**模拟盘跑不顺的策略，实盘必死；模拟盘跑顺了，也只过了工程关。**

## 8. 特别写给"用 AI 生成策略"的你：五条自保规则

AI 生成策略的最大风险：**AI 是一台没有纪律的过拟合机器**——你让它"优化"一个策略，它就会尽职尽责地给你调出一个完美贴合历史的参数，并且一本正经地告诉你它很有效。所以：

1. **AI 生成的策略默认按"过拟合嫌疑犯"处理**，举证责任在策略这边。
2. **留样本外底牌**：拿出 20-30% 的数据（或最近一年），任何调参都不许碰它，最后才看一次。
3. **参数扰动测试**：把参数上下拨 20%，结果断崖式变化 → 扔掉。
4. **一句话测试**：策略逻辑能用一句人话讲清（"买低波动的小市值，每月换一次"）→ 加分；讲不清 → 危险。
5. **成本翻倍压力测试**：把佣金+滑点调高一倍还能活，才算及格。

再加一条：**小资金实盘至少 3 个月**，跑通"信号→下单→成交→对账"全链路，再谈放大。

AI 的正确角色：**极快的实习生**——写代码、查数据、做实验、跑检验，它比人快一百倍；但研究纪律（样本外、扰动、成本）和"这个策略讲不讲得通"的判断，必须由你把关。

## 11. 小白误区清单（对照自查）

- ❌ "回测年化 50%！" → 先问：扣成本了吗？样本外呢？参数扰动呢？
- ❌ "夏普 3 好厉害" → 高夏普+高换手 ≈ 成本一加就现原形。
- ❌ "因子 IC 很高，能赚钱" → 第42课的反例就躺在本工作区。
- ❌ "AI 说这个策略有效" → AI 也会一本正经地过拟合，它没有样本外纪律。
- ❌ "最近三个月跑赢沪深300" → 样本太小，运气和实力的区分度约等于零。
- ❌ "回测里能成交" → 涨停/停牌/T+1 三个词了解一下（第39课）。
