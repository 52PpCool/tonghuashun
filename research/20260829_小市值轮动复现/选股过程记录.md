# 小市值轮动策略 · 同花顺智能选股复现过程记录

日期：2026-08-29
目标：用同花顺 iFinD 智能选股（`search_stocks`，自然语言选股）复现聚宽社区"小市值：不空仓-11年-收益535倍-年化79.96%"（guozong3）的**选股层条件**。

## 原策略的选股条件（来自帖子）

1. 股票池：中小板指成分股
2. 市值：10–100 亿
3. 单季度扣非净利润 > 0
4. 单季度营收 > 1 亿
5. 调仓：每周二，按市值/偏好在池内选 2–6 只持仓（这部分在聚宽代码里，选股层就是上面 4 条）

## 执行过程（每步都是真实调用，非臆测）

### 第 1 步：初试整段条件 → 失败

query：
> 中小板指成分股中总市值在10亿到100亿之间、最新单季度扣非净利润大于0、最新单季度营业收入大于1亿元的股票

返回：`count: 0`，"未找到符合要求的证券"。典型的多条件解析失败 / 条件组合无解，无法区分是哪种，于是拆开验证。

### 第 2 步：分解验证每个条件能否解析

| query | 结果 | 结论 |
|---|---|---|
| 总市值在10亿到100亿之间且扣非净利润大于0且营业收入大于1亿元的股票 | 2257 只 | 三个财务/市值条件能解析，但**扣非净利润、营收取了中报累计值**（`[20260630]`），不是单季度 |
| 中小100成分股中市值在10亿到100亿之间的股票 | 0 只 | 疑似池子没小票 |
| 中小板指成分股中市值大于500亿的股票 | 54 只（宁波银行、国信证券…） | "中小板指成分股"池子**能解析**，但成分股普遍大市值 |
| 中小板指成分股中市值最小的20只股票 | 最小市值为康弘药业 **191.7 亿** | 实锤：中小板指（中小100）成分股里**不存在** 10–100 亿的小票 |

> 中间还踩到一次 429 限流（免费版并发限制），后续把请求间隔拉到 3 秒以上。

### 第 3 步：修正"单季度"口径

query：
> 总市值在10亿到100亿之间且单季度扣非净利润大于0且单季度营业收入大于1亿元的股票

返回：1941 只，指标列变为 `单季度.扣除非经常损益后的净利润[20260630]`、`单季度.营业收入[20260630]` —— 单季度口径确认可用。这也正对应原帖作者强调的："分组条件扣非净利润条件要写'单季度扣非净利润'"。

### 第 4 步：换池子，跑真实条件

原帖的"中小板指成分股"在今天的样本结构下根本装不下小市值股票，实际应理解为"中小板全部股票"（002/003 开头）。

query：
> 中小板股票中总市值在10亿到100亿之间且单季度扣非净利润大于0且单季度营业收入大于1亿元的股票

返回：**352 只**，按市值排序。

### 第 5 步：发现分页截断 + 结果不稳定

- 单次返回的表格最多约 100–112 行，而声明数量更大 → 被截断；
- 相同 query 重复跑，数量在 352 / 322 之间波动 → 单次调用不可作为全量依据。

对策：把市值拆成 7 段分别查询，逐段核对"声明数量 == 表格行数"，再合并去重：

| 市值区间 | 声明数量 | 解析行数 | 完整? |
|---|---|---|---|
| 10–30 亿 | 53 | 53 | ✓ |
| 30–40 亿 | 52 | 52 | ✓ |
| 40–50 亿 | 58 | 58 | ✓ |
| 50–60 亿 | 61 | 61 | ✓ |
| 60–70 亿 | 40 | 40 | ✓ |
| 70–80 亿 | 30 | 30 | ✓ |
| 80–100 亿 | 53 | 53 | ✓ |

合并去重后：**347 只**。

### 第 6 步：收尾

- 临时取数脚本全部删除（skill 规范：用完即清）；
- 结果保存为 `search_all.csv`，按市值从小到大排序，放到工作目录 `/home/ppku/zcodespace/tonghuashun/`，不带入 skill 目录。
