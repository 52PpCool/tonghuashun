## 3. 核心发现展开

**Q1 行业**：电子(33)、通信(13)、机械设备(10)、电力设备(7)、基础化工(7)、医药生物(6)、有色金属(5)。十倍股高度绑定 2016-2026 的产业主线：半导体国产替代 + AI 光模块/CPO + 新能源。**没有一只"全能行业"，行业贝塔先于个股阿尔法。**

**Q2 上市时间**：老股（≤2015上市）仅 11 只（另有新易盛 2016-03-03、兆易创新 2016-08-18 两只 2016 年内早于窗口起点上市，按与市值锚定一致的严格窗口口径，老股合计 13 只、窗口内上市 75/88=85%），2016-2019 上市占 62 只。**"十倍股挖掘"在 A 股约等于"次新+成长股挖掘"**——老股盘子大、增长被摊薄，十倍弹性主要来自上市初的小市值高成长阶段。

**Q3 起点市值**：老股起点市值中位数 86.9亿 vs 次新 21.9亿；全样本 70% < 50亿，29 只 < 20亿。小市值→高弹性是十倍的必要非充分条件（同样的池子里，小市值没涨成十倍的是分母，见 §5 幸存者偏差）。

**Q4 时间**：按"收盘价首次 ≥ 10×窗口起点收盘"（不含盘中，系统性偏晚）。中位 5.2 年；Q4 最快三只海天精工(35天)/至纯科技(42天)/立昂微(60天)全部是**上市初期连板**的次新股，属于"打新收益"而非"持有收益"。

**Q5 回撤（本研究的招牌结论）**：**median -62.7%，75% 途中腰斩，最深 -82.7%**。即使你精准买中了未来的十倍股，大概率也要先忍受一次-60%级别的回撤。仓位管理（全景课28 Kelly）与"拿得住"的资金性质，比选股本身更决定成败。

## 4. 过程中的坑（真实留痕，全部已修复并记录）

1. **venv Python 失踪**：`.venv` 链接的 uv Python 3.12 被外部清理 → `uv python install 3.12` 重装后全套包完好，36课 `run_all.py` 恢复可跑。
2. **东财源封禁**：`stock_zh_a_hist` 首轮批量 88/88 全部 ConnectionError（IP 限频封禁）→ 切新浪源 `stock_zh_a_daily`（sz/sh前缀）+ 1s限速 + 指数退避重试，88/88 成功。两轮日志都在 `data/fetch_prices_log.txt`（append 模式，不覆盖）。
3. **`json.dumps` 默认转义中文**：解析市值时用 `json.dumps(dict)` 再正则，"亿"被转成 `\u4ebf`，单位识别失败按"元"÷1e8，市值整体缩小 1 亿倍（起点市值中位数一度显示 2.67e-07 亿）→ 改为直接在原始文件文本上正则（Node JSON.stringify 不转义中文）。
4. **复权口径差异**：按新浪前复权收盘线，86/88 摸到 10 倍；高争民爆（新浪+742% vs iFinD+1112%）、华盛昌（+671% vs +1010%）两只因复权基差异未触线。全样本涨幅两口径相关 0.977，中位绝对差 519pp——**"10倍"的判定对复权口径敏感**，这正是前轮研究记录的复权陷阱的又一次现身。
5. **停牌断档**：中际旭创 2016-09-30 起因重组长期停牌，新浪源无停牌行，其"窗口起点价"即停牌前收盘，复牌连板计入涨幅——起点定义用"窗口内首个交易日"，口径自洽。
   > **2026-10-01 工程篇39课复查修正**：停牌方向写反了。本课取数窗口从 2016-08-15 开始而 300308 首根bar为 09-30，说明停牌发生在 **2016-08-15~09-29、09-30 是复牌首日**（并非"09-30 起停牌"），复牌后节前收一日、节后 10-10~10-18 七连一字板。base_date=2016-09-30（窗口内首个可得交易日）与全部画像结论不受影响。详见 [工程篇39课实验3](../20261001_量化工程篇/39_自写事件驱动引擎/)。
6. **"次新占比"存在两种口径（2026-10-01 深度审查发现并修复）**：`summary.json` 初版只有年份口径（上市年≤2015，11 只），而市值锚定用的是严格窗口口径 `listed_before_window`（2016 年内早于 09-01 上市的新易盛/兆易创新也算老股，13 只），75/88 与 88-11=77 两数并存易误读；下游对照研究的 H2 初版误用了年份口径（详见[对照轮的修正记录](../20261001_伪十倍股对照画像/README.md)）。现已让 `summary.json` 同时落两种口径（`listed_before_2016`=11、`listed_before_window`=13、`listed_inwindow_strict`=75），本 README §1/§3 与对照轮全部统一为严格窗口口径。

## 5. 幸存者偏差声明（必须读）

88 只是 **2026 年回看仍活着、且区间涨满 10 倍** 的股票。同期退市、归零、 or 涨了 300% 然后跌回的几千只股票不在池内。因此：
- 本画像描述的是"十倍股长什么样"，**不是**"买入符合画像的股票有 x% 概率成为十倍股"；
- Q5 的回撤分布同样只统计"最终活成十倍"的路径——没扛过回撤的失败者连被统计的资格都没有；
- 教学连接：全景课 05/07 讲幸存者偏差，课 16 讲为什么"画像选股"回测必须加约束。
