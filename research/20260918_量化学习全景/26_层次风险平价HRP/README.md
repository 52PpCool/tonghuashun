## 一、这节课学什么

1. **协方差求逆是马科维茨体系的阿喀琉斯之踵。** 最小方差组合需要 Σ⁻¹；N 大、T 短或资产高相关时，
   Σ 病态（条件数爆炸甚至不满秩），逆矩阵把估计误差放大后吐回权重里——权重极端、日日翻脸。
2. **HRP 用三步"树形"流程绕开求逆**：树聚类（谁跟谁像）→ 准对角化（把像的排在一起）→
   递归二分（沿树分蛋糕）。全程只有矩阵乘法、开根号和除法。
3. **聚类是"降维的智慧"**：它不要求精确解，只要求"别把相似资产当成两笔独立分散"——
   这正是机器学习"结构重于精度"的思想第一次进入组合构建。
4. **稳健性要用实验证明，不是用口号宣称。** 本课把相关矩阵加噪后重测：协方差良态时最小方差
   甚至更稳（如实报告）；一旦矩阵病态（N=100、T=60<N，秩 59），最小方差权重漂移是 HRP 的 3 倍多。
5. **诚实的回测不会永远偏向新方法。** 在 10 行业、252 日窗口的真实回测里，最小方差夏普 0.47、
   HRP 只有 0.15（rf=2% 口径）——原因不是 HRP 不行，而是本例 N 太小、Σ 太良态。看懂"什么时候轮到 HRP 上场"
   比记住公式重要。

先修：09（马科维茨有效前沿）、10（风险平价与资产配置）。新工具只有三个：
`scipy.cluster.hierarchy` 的 linkage / dendrogram、递归二分、cvxpy 的 QP 求解（对照组用）。

## 二、核心概念

### 2.1 为什么"协方差求逆"在 N 大时会病态

最小方差组合 `w* = Σ⁻¹·1 / (1'Σ⁻¹1)`。求逆对输入误差的放大倍数由**条件数**
`κ = λ_max/λ_min` 决定：Σ 的特征值越小（越接近奇异），逆矩阵里的 1/λ 越炸。

三种典型病态场景：

- **T < N**：样本协方差 `Σ̂ = X'X/(T-1)` 的秩最多 T−1。N=100 只资产、60 天样本 → 秩 59，
  严格不可逆，只能伪逆（把 59 个非零方向放大到天上）。
- **高相关**：两只 ρ≈0.95 的资产在 Σ 里几乎线性相关，λ_min→0，求逆后权重出现
  "+80% A、−80% B"这种靠抵消才能成立的极端多头空头结构（长只能约束能压制一部分，但方向已坏）。
- **估计噪声**：Σ̂ 本身是估计量，误差经 Σ̂⁻¹ 放大——条件数 103 的矩阵（本课真实数据）误差放大
  还温和；κ 上万时权重就是噪声放大器。

本课真实 10 行业全样本相关矩阵特征值范围 [0.047, 4.820]，条件数 ≈ 103——**良态**，
这是后文回测里最小方差表现好的根本原因，也是实验 A 里它不输 HRP 的原因。

### 2.2 树聚类：距离怎么选，single 还是 ward

**第一步：相关系数 → 距离。** 直接用 `1−ρ` 当距离不行（不满足三角不等式）。
López de Prado 用 `d = √(0.5(1−ρ))`：开根号后 d 是严格度量（ρ=1 → d=0，ρ=0 → d≈0.707，
ρ=−1 → d=1）。坑：**要喂给 linkage 的是距离，不是相关系数**（见"常见的坑"第 1 条）。

**第二步：linkage（连接方式）怎么选。** 本课两种都试了（图 1 左右并排）：

- **single（最近邻，论文原版）**：两簇距离 = 最近的两点距离。容易产生"链"状合并，
  换来的是只保证一件事——**相邻的叶子相似**。这恰好是 HRP 需要的全部：第 3 步递归二分
  只按顺序切，不关心簇的形状。对不规则的相关结构也最宽容。
- **ward（最小方差增量）**：合并时最小化"簇内方差增量"，树更均衡漂亮，但它的数学假设是
  欧氏坐标下的方差，用在相关距离上属于"借用"（数值上能跑，语义上打了折扣）。

本课主回测沿用论文的 single。真实数据里两种链接给出的顺序不同（single：半导体→银行→汽车整车→…
→电力；ward：银行→煤炭→电力→半导体→…），说明**树结构本身就是估计量**——这是"常见的坑"
第 3 条（权重翻脸）的根源。

**聚类结果的经济直觉（真实数据）**：最早合并的是**保险 + 证券**（d=0.179，ρ≈0.94）——
大金融的"Beta 双子星"；随后房地产开发加入金融簇（d=0.441）；**白酒 + 医疗器械**
（d=0.442，ρ≈0.61）抱团；**煤炭 + 电力**（d=0.511，ρ≈0.48）同属上游能源。符合经济直觉：
相关系数"看见"了行业间的共同定价因子。

### 2.3 准对角化（quasi-diagonalization）的意义

把聚类树"展开"成叶子顺序（seriation），按这个顺序重排协方差/相关矩阵——重排后**大相关值
聚到对角线附近成"块"**（图 2 右）。它叫"准"对角化是因为**不可能**把所有资产排成完美分块
（A 像 B、B 像 C、A 不像 C 的三角关系总会存在），只能让相似资产尽量挨着。

意义有二：其一，它把"资产列表"变成"有序列表"，是第 3 步按序二分的前提；其二，它是纯粹的
**重排操作（置换矩阵）**，不改变矩阵本身，也不引入任何新估计——免费的。

### 2.4 递归二分分配的直觉

分蛋糕规则只有一条：**每一刀把当前簇切成左右两半，两半各先用逆方差权重（IVP）算出
簇方差，然后按逆方差比例分钱——方差大（更危险）的那半少分。** 反复切到叶子。

- 簇方差 `Var(簇) = w'Σw`（w 取簇内 IVP）：注意它用的是**完整子协方差块**（含簇内资产的
  相互协方差），所以 HRP 并没有扔掉相关系数；它扔掉的是**跨簇之间的协方差**（下一半分配
  时不再问"左半和右半像不像"）——这正是它的简化近似：牺牲全局最优性，换取对估计误差的钝感。
- 权重 = 每片叶子沿途收到的比例**乘积**。每层的分配比例天然和为 1，所以**总权重恒等于 1**，
  HRP 不需要事后归一化（见"常见的坑"第 2 条）。
- 为什么不用"求出精确的最优分割"？因为精确解又要把 2×2 的跨簇协方差请回来——HRP 的全部
  设计哲学就是**宁可次优，不要病态**。

### 2.5 HRP vs 马科维茨 vs 朴素风险平价

| | 马科维茨/最小方差 | 朴素风险平价（逆波动率） | HRP |
|---|---|---|---|
| 用到的输入 | 完整 Σ（含均值可选） | 只有对角线（方差） | 相关矩阵的**结构** + 方差 |
| 需要求逆 | 要 | 不要 | 不要 |
| 对估计误差 | 最敏感（κ 放大） | 最钝感 | 中间偏稳（簇结构钝感） |
| 数学性质 | 二次规划最优解 | 启发式 | 启发式（二分路径最优、全局次优） |
| 擅长场景 | N 小、Σ 估计可靠 | 极简、抗造 | **N 大、相关分层复杂、Σ 病态** |

可以把三者看成一条光谱：朴素 RP 完全无视相关结构（太浪费），马科维茨完全信任相关矩阵
（太天真），HRP 取中——**只用相关的"排序/结构"信息，不用它的精确数值**。聚类把连续的
ρ 离散化成"谁挨着谁"，离散结构对噪声的耐受度天然高于连续数值。

### 2.6 López de Prado 其人

Marcos López de Prado：量化行业旗手级人物，康奈尔大学博士，曾任 Guggenheim Partners 量化
主管、AQR Capital 机器学习负责人，后来在 ADIA（阿布扎比投资局）任 Global Head of
Quantitative R&D，并任教于康奈尔。他把机器学习系统性引入投资流程的代表作是《Advances in
Financial Machine Learning》（2018，中译《金融机器学习进展》），而 HRP 出自他 2016 年的论文
*Building Diversified Portfolios that Outperform Out-of-Sample*（Journal of Portfolio
Management）——该论文的核心贡献不是"又一个配置公式"，而是证明了**组合构建可以不从优化
问题出发，而从数据的结构（树）出发**，且样本外更抗打。他也创造了 "fractional differentiation"、
"meta-labeling" 等概念，是当代量化从业者绕不开的名字。

### 5.3 噪声实验：权重漂移 L1 = Σ|w_noisy − w_baseline|（rng(42)）

**实验 A：真实 10 行业（协方差良态），每个幅度 20 次重复**

| sigma | 最小方差漂移 | HRP 漂移 |
|---|---|---|
| 0.05 | 0.100 | 0.229 |
| 0.10 | 0.201 | 0.286 |
| 0.20 | 0.326 | 0.332 |
| 0.30 | 0.531 | 0.306 |
| 0.50 | 0.632 | 0.407 |

**如实解读**：小噪声（sigma ≤ 0.2）时**最小方差反而更稳**（0.20 vs 0.29）；
sigma=0.30 时 HRP 反超（最小方差漂移是 HRP 的 **1.7 倍**）。两条曲线形状揭示了机制：
最小方差漂移随噪声**近似线性放大**（求逆是线性算子，误差线性传导）；HRP 漂移有约
0.23 的"地板"（树结构离散翻转）但**增长缓慢并趋于饱和**。交叉点落在 sigma 0.2~0.3 之间。
**结论要讲全：协方差良态时别神化 HRP；它的"稳"在输入被污染得更狠时才兑现。**

**实验 B：合成 N=100、T=60 < N（协方差秩 59，严格不可逆）【合成数据】，每个幅度 10 次重复**

| sigma | 最小方差漂移 | HRP 漂移 |
|---|---|---|
| 0.05 | 0.328 | 0.233 |
| 0.10 | 0.604 | 0.261 |
| 0.20 | 0.876 | 0.288 |
| 0.30 | 1.064 | 0.340 |
| 0.50 | 1.217 | 0.382 |

病态场景下高下立判：sigma=0.5 时最小方差漂移是 HRP 的 **3.2 倍**。基准权重也说明问题：
最小方差组合有效资产数 1/Σw² 只有 **11.8**（100 只资产里实际押注十来只，最大单权重
17.9%），HRP 有效资产数 **88.6**（最大单权重仅 2.1%）。**这才是 HRP 论文瞄准的主场：
N 大、T 短、Σ 求不了逆——HRP 不求逆，所以噪声传不进权重。**

## 六、常见的坑（本课开发中真实踩过前两条）

1. **聚类喂了相关系数而不是距离。** `linkage(corr)` 直接跑不会报错，但相关系数不是距离
   （1−ρ 不满足三角不等式，ρ 可以是负的），聚类结果无意义。必须先过
   `d = √(0.5(1−ρ))`（`corr_distance`，L130），再用 `squareform` 压缩成 condensed 向量。
2. **重排与权重对齐搞反（张冠李戴）。** 论文原版 `getRecBipart` 用 `pd.Series(index=sort_ix)`
   按资产标签记账，返回前 `sort_index()` 就回到原始顺序；本课 numpy 版按下标=资产编号
   记账，返回的已经就是原始顺序。开发时我在 `hrp_weights` 里又按 `order` 重排了一次，
   结果权重全体错位（银行拿到半导体的权重），回测与全样本权重全错——而且因为乘积结构
   权重和恒为 1，**错误完全不报错**，只能靠"低波动行业不该只有 5%"这类经济直觉抓出来。
   教训：写完 HRP 先检查两件事——权重和是否为 1、权重与波动率的相关符号是否合理。
3. **滚动窗口太短 → 树结构频繁跳变 → 换手飙升。** 本课 252 日窗口下 HRP 单次换手已达
   9.10%（朴素 RP 2.57%）；把窗口压到 60 天，相邻两个月的相关矩阵会让 保险-证券 和
   银行-房地产开发 反复合桶又散伙，二分路径大改，权重月月翻脸，交易成本吃掉全部理论收益。
   药方：加长窗口、对相关矩阵做指数加权平滑、或对聚类结果做"粘性"处理（只有合并距离
   变化超阈值才允许改树）。
4. **把 HRP 当"免估计误差"神药。** 实验A如实显示 HRP 有约 0.23 的漂移地板，且它仍然
   完全依赖相关矩阵的估计（ρ 变 → 树变 → 权重变）。HRP 降低的是**对误差的敏感度**
   （不求逆、只用结构信息），不是**对估计的依赖**。协方差良态时它甚至可能输给最小方差。
5. **（附）噪声扰动后的矩阵忘了 PSD 修复。** 给相关矩阵加大幅扰动后会出现负特征值，
   cvxpy 的 `quad_form` 直接报错。要么 `psd_wrap` 跳过检查，要么特征值截断
   （`psd_repair`，L368）——本课用后者并保证最小方差与 HRP 吃进同一个修复后的矩阵，对比才公平。

## 七、延伸思考（练习）

1. **换链接方式跑全程**：把 `hrp_weights`（L248）里 `cluster_corr` 的 method 从 "single"
   改成 "ward"（或 "average"/"complete"），重跑回测。对比四项指标与换手率的变化：
   更均衡的树是否带来更低的换手？夏普变大还是变小？（本课图 1 已给出两棵树的形状差异。）
2. **HRP + 波动率目标**：HRP 是纯配置，不管组合波动绝对水平。仿照课 10 的波动率目标策略，
   在 HRP 之上叠加现金腿把组合波动压到 10% 年化，看夏普与回撤如何变化。
   （提示：杠杆后权重和 >1，注意融资成本可以先忽略。）
3. **把 N 从 10 提到 38**：`data/cache/` 里还有 28 只个股 CSV（stock_*.csv）。把行业与个股
   混在一起跑 HRP，观察树状图层次（个股聚在行业簇下）与权重赫芬达尔指数的变化；
   再把估计窗口降到 60 天，复现实验 B 的病态场景在真实数据上的样子。
   （提示：`load_returns` 里把 stock_* 也读进来即可，注意部分个股起始日期不同，内连接会自动对齐。）
