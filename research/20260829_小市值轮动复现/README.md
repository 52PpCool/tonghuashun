# 2026-08-29 小市值轮动策略·iFinD 智能选股复现

## 任务说明

用同花顺 iFinD 智能选股（`search_stocks`，自然语言选股）复现聚宽社区帖"小市值：不空仓-11年-收益535倍-年化79.96%"（guozong3）的**选股层条件**：

- 股票池：中小板（002/003 开头；原帖写"中小板指成分股"，实测该指数内无 10–100 亿小票，故按中小板全板理解）
- 总市值 10–100 亿（2026-08-28 收盘）
- 单季度扣非净利润 > 0（2026 中报）
- 单季度营收 > 1 亿（2026 中报）

## 方法与过程要点

完整 6 步试错过程见 [选股过程记录.md](选股过程记录.md)。关键点：

1. 整段多条件 query 初次失败（count=0），逐步拆解定位：财务三条件可解析但默认取中报累计值，需显式写"单季度"；
2. "中小板指成分股"池子能解析但成分股最小市值 191.7 亿，装不下小票 → 改用"中小板股票"；
3. 单次返回表格约 100 行即被截断且数量在 352/322 间波动 → 按市值拆 7 段查询，逐段核对"声明数量 == 表格行数"后合并去重得 **347 只**；
4. 中间踩到 429 限流，请求间隔拉到 3 秒以上。

## 结论

**347 只中小板股票**满足条件，最小市值 18.4 亿（中天服务 002188），含 ST 股（原帖未排除）。数据快照为 2026-08-28 收盘 + 2026 中报。
