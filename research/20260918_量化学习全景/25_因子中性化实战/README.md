# 25 因子中性化实战：把"沾了别的因子光"的收益剥干净

> 量化研究员每天都在做的活。你挖到一个"动量因子"，IC 看起来不错——但它可能只是在替
> **低波动风格**打工、或者在替**某个行业抱团**打工。这节课用同一份月度截面，对动量因子做
> 三种处理并对比 IC，亲眼看清"中性化"到底剥掉了什么、剩下了什么。
>
> 数据：`data/cache/` 30只真实A股日K（前复权，2018起）；随机种子 42；运行约 4 秒。

---

## 1. 这节课学什么

上一课（05_因子分析与分层回测）你学会了算 IC。这一课回答一个更刁钻的问题：

**你的因子 IC 里，有多少是"别人家的收益"？**

- 动量因子做多的高分股，恰好是低波动股票 → 你的"动量 alpha"里混着低波动风格的钱；
- 动量因子多头集中在银行、空头集中在白酒 → 你的"动量 alpha"里混着行业赌注的钱。

中性化（neutralization / 正交化 orthogonalization）就是把这两部分剥掉，只留下
"行业内、风格中性的**纯 alpha**"。学完你将掌握：

1. 横截面回归取残差——一切因子加工的基本功（公式见 §2.2）；
2. 行业中性化的两种等价做法；
3. 正交化的**顺序敏感性**与联合回归；
4. 中性化"降 IC、提纯度"的取舍，以及如何用多空组合行业暴露验证；
5. 为什么这些结论都建立在"30只窄截面"的局限上（§7 严谨性声明）。

## 2. 核心概念

### 2.1 为什么原始因子的 IC 会"虚高"——风格暴露

IC 衡量"因子排序 → 下月收益排序"的预测力。但因子之间彼此相关：本课实测，
**动量与低波动（-60日波动率）的月度 Spearman 相关均值 -0.126，10%分位 -0.746、
90%分位 +0.447，平均 R²（相关平方）≈ 0.211**——动量的截面排序有相当一部分月份里
约五分之一甚至一半的差异能被"低波动"解释。低波动在 A 股长期有溢价，于是原始动量
的 IC 里天然含着"低波动那部分钱"。行业同理：动量因子往往系统性做多某些行业、做空
另一些行业，这属于**行业赌注**而非选股能力。不做中性化，你无法区分
"我会选股"和"我恰好站在了对的风格/行业上"。

### 2.2 横截面回归取残差的公式

每个**月末截面**上（注意：不是时间序列回归！），把动量 y 对条件因子 x 回归：

```
beta = (x'x)^(-1) x'y        # 单因子，含常数项
resid = y - alpha - beta·x   # 残差 = x 解释不掉的部分
```

残差就是"剥掉 x 之后还剩下的动量"。多因子同理：把 x 换成矩阵 X（各列一个因子 +
常数列），`beta = (X'X)^(-1)X'y`，`resid = y - X@beta`。代码实现见 `main.py` 第
**161-179 行**的 `ols_resid()`（用 `np.linalg.lstsq`，比手动求逆对共线/退化更稳）。

**关键性质**：残差与 X 中每个因子（含常数列）的样本 Pearson 相关**严格等于 0**——
这是 OLS 的一阶条件决定的，不是近似。所以"剥谁、谁与动量的线性相关就归零"。

### 2.3 行业中性化的两种做法

- **做法一：行业哑变量回归取残差**（本课主用，`main.py` 第 **181-199 行**
  `industry_neutral_residual()`）。构造 X = [1, D₂, …, D_K]，D_k 是"是否属于行业 k"
  的 0/1 哑变量（第 194 行；第一个行业当基准组不进 X，避免完全共线）。残差 =
  剔除每个行业平均动量水平后的部分。
- **做法二：行业内 z-score**（`main.py` 第 **202-214 行** `industry_zscore()`）。
  在每个行业内部减组内均值、除以组内标准差。

由 **Frisch–Waugh–Lovell 定理**，做法一的残差 = 因子减各自行业均值（组内去均值），
与做法二只差一个"是否再除以组内标准差"的缩放，**秩几乎相同**。本课实测两种做法
RankIC 均值 +0.0150 vs +0.0207、多空年化 +13.2% vs +11.8%——接近但不完全相同
（z-score 版额外做了组内波动调整，且单股票行业处理略有差异）。

### 2.4 正交化的顺序：残差化不可交换

先剥 A 再剥 B ≠ 先剥 B 再剥 A。记 r_ab = res(res(动量|A)|B)（A=低波动，B=规模代理
log价格）：

- **暴露签名**（月均 |Pearson相关|）：r_ab 与 B 相关 = **0.000**（最后剥的，严格归零），
  与 A 残留 **0.081**（先剥的会"回渗"回来）；r_ba 镜像：与 A = 0.000、与 B = **0.143**。
  → **你最后剥掉的因子，被剥得最干净。顺序体现研究假设：你最不想要什么暴露，就把它放最后。**
- **数值差异**：corr(r_ab, r_ba) 月均 0.961、最低月 0.749——不可交换是数学事实，但
  差异是二阶小量，条件因子越相关、样本越小差异越大。本课两种顺序的 IC 分别为
  **+0.0463 vs +0.0544**：顺序真的会改变结论数字。
- **正规做法**：把 A、B 放进**同一个联合回归** r_joint = res(动量 | A+B)，残差同时对
  A、B 严格归零（实测暴露签名 0.000/0.000），完全不依赖顺序。这就是 Barra 类风险
  模型的思路（见 §2.6）。本课实测 corr(r_joint, r_ab)=0.992、corr(r_joint, r_ba)=0.970。

### 2.5 中性化的取舍：IC 降了，但更"干净"

中性化剥掉的是"风格/行业那部分收益"，剩下的才是纯选股信息——所以 **IC 通常下降**
（信息变少），但剩下的 IC 更可信：不靠风格抱团、不靠行业赌注，策略容量和风险特征
也完全不同。**注意它不一定降**：如果被剥掉的暴露在本样本恰好是拖累，IC 反而可能
上升（本课剥低波动后 IC 就略升了，见 §5）。同时别忘了：中性化后的因子**换手更高、
交易成本更大**（多空两边名单都变了，见 §6 坑3）。

### 2.6 Barra 风格风险模型一句话

Barra（CNE5 等）的做法正是本课方法的"工业级完整版"：用**几十个风格因子（市值、
 beta、动量、波动、价值…）+ 几十个行业哑变量**对个股收益做**联合横截面回归**，
把每只股票的收益分解成"行业贡献 + 风格贡献 + 特质收益"，再据此构造纯因子组合
（pure factor portfolio）、做组合风险分解和业绩归因。你在这节课学的"回归取残差"，
就是它的最小可运行版本。

3. **两种行业中性做法数字接近**（0.015 vs 0.021），验证了 FWL 定理：哑变量回归残差

## 6. 常见的坑

1. **用未来的行业分类回测历史**。公司会转型、改名、被重新分类（如隆基绿能从半导体
   设备切到光伏）。本课 30 只大盘蓝筹行业相对稳定，但严格做法应使用**历史时点的
   行业归属**（如当时的申万一级行业），否则等于偷看答案。
2. **中性化后忘了重新标准化**。回归残差的方差比原始因子小得多，直接拿去和别的月份/
   别的因子比较会失真。本课每次取残差后都重新 z-score（`main.py` 第 313-315 行的
   `zscore(...)` 包装），再进 IC/多空计算。
3. **把正交残差当"新 alpha"，却忘了成本一分没扣（多空两边都要付）**。表里的 IC 和
   多空年化全部是**零成本**数字，而多空组合每边都要按月按新名单调仓付费。本样本
   多空 20 只月均换血约 18%（原始动量 17.8%、行业中性 18.1%）；2024-07→08 那次
   原始只换 2 只（10%）、中性换 5 只（25%）——中性化剥掉慢变的风格/行业成分后，
   剩下的特质排序在风格切换期会显著加大调仓。费后收益会明显低于表中数字
   （参见第16课的成本敏感性）。
4. **小截面回归不稳定**。30 只票做 11 个行业哑变量回归，自由度只剩 30-11-1=18，
   组内 z-score 在两三只票的组里噪声极大；某行业当月只有 1 只有效样本时其残差只能
   置 0/缺失。小截面的中性化结果对行业划分方式非常敏感——换个分组结论可能就变。
5. **Pearson 与 Spearman 背离，极端值主导回归**。规模代理若用原始价格（茅台 1400 元
   vs 银行股 11 元），其与低波动的月均相关 Pearson 仅 0.09、Spearman 却有 0.40——
   回归被高价股一家主导。取 log 后两者接近（0.344 / 0.396）。同理，正交化只保证
   **线性（Pearson）相关归零**，图02 中低波正交动量与低波动的秩相关仍残留 +0.09。

## 7. 严谨性声明

- **窄截面**：只有 30 只股票、11 个行业，多空各 10 只（1/3），统计功效很低
  （IC t 值 1~2 量级，均不满足严格显著）。
- **幸存者池**：30 只都是活到今天的大公司，天然幸存者偏差，动量/低波溢价在此池内
  未必代表全市场。
- **无真实市值/估值数据**："规模代理"只是 log(价格水平)——价格与市值正相关但股本
  各异，是真代理、不精确。行业归属是硬编码的公开分类近似。
- 本课重点是**中性化方法论本身**（回归取残差、行业中性、顺序、联合回归），
  数字大小不构成任何投资结论。

## 8. 延伸思考（练习）

1. **换真市值**：把规模代理换成真实流通市值（需要股本数据），重跑顺序敏感性实验。
   观察 corr(低波动, 规模) 和 corr(r_ab, r_ba) 如何变化——真实市值与波动的相关性
   通常比 log 价格更强，顺序问题会被放大还是缩小？
2. **双重中性化**：对动量同时做"行业 + 低波动"处理——分别试"先行业后低波"的顺序
   残差化与"行业哑变量+低波动"放在一起的联合回归，比较两者的 RankIC 与暴露签名，
   验证 §2.4 的结论。
3. **特质动量**：把行业中性残差再除以"特质波动率"（行业内残差收益的波动），得到的
   就是学术上有名的 idiosyncratic momentum（Blitz et al. 2011）。用本框架算出它的
   IC，看风险调整是否比裸残差更强。
