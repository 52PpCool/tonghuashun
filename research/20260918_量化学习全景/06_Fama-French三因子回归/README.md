> 前置：第05课讲了"因子能不能预测收益"（截面视角）。本课换一个视角：**对单一股票/单一策略，

> 这是评估任何基金经理、任何选股策略的标准动作——先问一句：**你赚的钱，是模型解释不了的，
> 还是只是押对了风格？**

## 2. 核心概念

### 2.1 FF3 模型公式（时间序列回归）

```
Ri − RF = a + b·(Mkt−RF) + s·SMB + h·HML + ε
```

对**一只股票**，把它每个月的**超额收益**（个股月收益 − 当月无风险利率）作为因变量，
把三个因子作为自变量，用普通最小二乘（OLS）估计。四个输入列的含义：

| 列 | 含义 | 直觉 |
|----|------|------|
| `Mkt-RF` | 市场因子 = 全市场组合收益 − 无风险利率 | "这个月大盘水位涨了多少"。本数据 1926-07~2026-07 全样本年化均值 **+8.33%** |
| `SMB` | Small Minus Big：小盘股组合 − 大盘股组合 | "小公司比大公司多赚多少"。长期年化均值 **+1.99%**（规模溢价） |
| `HML` | High Minus Low：高B/M（价值股）− 低B/M（成长股） | "便宜股票比贵的股票多赚多少"。长期年化均值 **+4.26%**（价值溢价） |
| `RF` | 无风险利率（月度，美国一个月期国库券口径） | 长期年化均值 **3.24%**，是"什么都不干也能拿到的钱" |

（以上长期均值来自 `data/cache/ff3_monthly.csv` 全样本 1201 个月的实际计算，脚本运行时打印。）

**回归输出怎么读：**

- **a（截距）= alpha**：三个因子都解释不掉的**月均**超额收益。它为正且统计显著 → 这只股票/策略真的"有东西"；它不显著 → 收益基本可以被风格暴露解释，没有什么独家本事。
- **b / s / h（斜率）= 三个 beta（风格暴露）**：b=1.7 意思是"市场每涨1%，它平均多涨0.7%"。**beta 不是能力，是仓位特征**——你只要加杠杆买指数基金就能把 b 做到 1.7。
- **R²**：三个因子解释了超额收益**方差**的多大比例。注意：R² 高低与"有没有 alpha"**无关**——R²=55% 只说明"一半多的波动来自风格"，alpha 是在"扣掉风格"之后剩下的**均值**部分。

### 2.2 alpha 与 beta 的本质区别（本课灵魂）

| | beta（风格暴露） | alpha（选股能力） |
|---|---|---|
| 是什么 | 对已知风格因子的敏感度 | 因子解释不掉的剩余收益 |
| 能否"买到" | **能**：买指数基金+杠杆，或按市值/价值分组构建组合 | **不能直接买**：这正是它的价值所在 |
| 要不要付钱 | 理论上要付"因子溢价"（承担风格风险的对价） | 理论上应该归"真本事" |
| 评估时 | 先扣掉（控制变量） | 剩下的才谈本事 |
| 典型误读 | "这股票十年涨了60倍！" ← 可能只是beta 1.7赶上大牛市 | 把高beta当成选股能力（本课最常见的坑） |

**为什么必须用超额收益（Ri−RF）回归，而不能直接用总收益 Ri？**
如果用总收益，"无风险利率"这一块会混进截距：回归实际上变成
`Ri = a' + b·(Mkt−RF) + …`，此时 a' = alpha + b·RF 的近似——在利率长期 3%+ 的环境里，
alpha 会被凭空抬高一截。正确做法是两边都减掉 RF，让 alpha 干干净净地只代表"超额部分的能力"。
（本课代码：`excess = rets[code] - ff3['RF']`。）

**SMB / HML 的直观解释（为什么是"差值"？）**
- SMB = 小盘组合收益 − 大盘组合收益：做多小盘、做空大盘的**多空对冲组合**。它把"市场涨跌"完全对冲掉，剩下的纯粹是"小公司相对大公司的差异"。回归里 s>0 表示这只股票像小盘股一样动，s<0（本课三只全是负的，如 MSFT 的 **−0.75**）表示它是典型的"大市值"股票——大盘股跌它才涨，这就是暴露。
- HML = 高账面市值比(B/M)组合 − 低B/M组合：做多"便宜的价值股"、做空"贵的成长股"。h<0（本课三只均为负，NVDA 达 **−0.95**）= 典型的成长股特征：市场给未来讲故事时它涨，市场转向"便宜实在"时它跌。**风格暴露本身无好坏**，它告诉你"你的收益是靠什么风格的风吹来的"。

### 2.3 Newey-West 标准误为什么需要

OLS 的 t 值计算假设残差**无自相关、同方差**。金融月收益的残差两样都违反：
波动有成簇性（大月连着大月），残差也常有轻微自相关。后果是**普通标准误被低估 → t 值虚高 →
把运气当成显著**。Newey-West (1987) 的 HAC（异方差自相关稳健）标准误对这两者同时修正。
窗宽用自动规则 `floor(4·(n/100)^(2/9))`：本课全样本 n=139 → maxlags=4；滚动窗口 n=36 → maxlags=3。
本课回归中残差的 Ljung-Box(6) 检验 p 值为 0.390 / 0.063 / 0.602（AAPL/MSFT/NVDA），
自相关不算严重，但 MSFT 已在 10% 边缘——用 NW 是稳妥的默认选择（详见 `regression_detail.txt`）。

**月度对齐的三个易错点（都在代码注释里）：**
1. 因子数据单位是 **%**，必须 ÷100 才能与 yfinance 的小数收益相减，否则 RF 一项会放大100倍；

## 6. 迁移思考：A股如何自建 SMB / HML

美国因子是 Kenneth French 免费维护的，A股没有官方版——**自建因子是A股量化入门的第一道真功夫**。
方法（Fama-French 2×3 独立排序法，示意图 `outputs/05_A股自建因子示意.png`）：

1. **数据**（每月末截面）：全市场A股（**必须含已退市股**，否则幸存者偏差）的流通市值、账面净值、收盘价；算出账面市值比 B/M = 账面净值 / 总市值。akshare 的个股指标/财报接口可取。
2. **独立双重排序**：先按流通市值用**中位数**切成 小盘S / 大盘B 两组；再在每组内部按 B/M 切成 低(成长)30% / 中40% / 高(价值)30% —— 得到 2×3 = 6 个组合。
3. **组合收益**：6 个组合各做成等权（或市值加权）组合，每月末调仓，记录月收益。
4. **合成因子**：
   - `SMB = 均值(S/L, S/M, S/H) − 均值(B/L, B/M, B/H)`（规模维度，价值/成长组内先平均掉）
   - `HML = 均值(S/H, B/H) − 均值(S/L, B/L)`（价值维度，规模组内先平均掉）
5. 把自家 SMB/HML 与 `沪深300 − RF`（或中证全指−RF）作为三因子，代回本课的 `ff3_regression`，就得到**A股口径**的 alpha 与 beta。

**用本课 data/cache 的 30 只大盘股池能做吗？**——只能做"思路演示的退化版"：按市值排序前15只当大盘组B、后15只当小盘组S，两组等权收益之差当作SMB。但必须诚实：① 这30只全是当今知名**大盘**股，"小盘组"只是"相对小的大盘股"，做不出真正的规模溢价；② 缓存里没有市值/财务数据（B/M 算不了）；③ 股票池是按"今天还活着"挑的（幸存者偏差）。**严肃的A股三因子研究必须用全市场时点股票池 + 含退市股 + 真实市值与财报。**

## 7. 常见的坑（每一条都能让结论全错）

1. **用总收益回归，忘了减 RF**：alpha 会被无风险利率污染。年化 RF 约 3%+ 的环境里，11 年半能"白送" alpha 三四个点（b·RF 项），足以把"不显著"洗成"显著"。本课第一步就是 `excess = rets − ff3['RF']`。
2. **月频 alpha 忘了年化（或错误年化）**：回归输出的截距是**月度**量纲。NVDA 的月 alpha "+3.34%" 听起来平平无奇，年化是 `(1+3.341%)^12 − 1 ≈ 48.3%` 的复利口径；而本课拆账表用的是算术口径 `3.341% × 12 = 40.1%`（OLS 拆账用的是均值恒等式，两种口径都要心里有数，**切忌直接拿月 alpha 和别人年化数字比大小**）。反过来，把年化 alpha 当月 alpha 又会夸大 12 倍。
3. **把高 beta 误当成选股能力**：看见"十年 60 倍"先查 beta。NVDA 年化超额 +61.2% 里，风格暴露贡献 +21.1%/年——任何 beta 1.7 的持仓在那样的牛市里都能吃到这一段；"涨得多"和"有本事"之间隔着一次回归。
4. **幸存者偏差 + 样本太短**：本课三只股票是"事后挑出的赢家"（今天的巨头），它们的平均 alpha 天然偏乐观；139 个月里 NVDA 的滚动 alpha 也曾连续三年为负。给任何策略算 alpha，请用**时点股票池**（含退市股）并做跨周期检验。
5. **（附送）不看残差诊断就报 t 值**：MSFT 残差峰度 8.3、JB 检验 p<0.001——厚尾之下，普通 t 值不可信；本课从第一行代码就用了 Newey-West 标准误，这是"跑回归"和"用回归下结论"的区别。

## 8. 延伸思考（练习）

1. **换因子库**：Kenneth French 官网还有五因子（+RMW 盈利、CMA 投资）与动量因子(MOM)数据。下载后把本课回归扩成五因子：NVDA 的 alpha 会缩水多少？（提示：成长股的 alpha 很可能有一部分被 RMW/CMA 解释。）
