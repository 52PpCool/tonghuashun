## 已知数据质量问题（各课 README 中均有对应处理与记录）

1. **行业板块数据基期跳变**：东财板块/ETF 源存在基期切换造成的单日 ±35%~66% 假跳动（共约29处，如房地产开发2024-08-09单日-63.7%）。点子10、15 的代码内置了跳变清洗（单日|收益|>30%判为跳变置0），其他课直接用行业数据时也建议先清洗。
2. **沪深300缓存非指数点位**：见上表；跨课比较时以相对收益为准。
3. **个股单日异常**：茅台缓存 2018-10-29 的 open=close=前收（行情错位），致次日"单日-15.21%"实为两日累计（点子11核验）。
4. **缓存缺行**：2019-04-29/30 对 24/30 只股票缺行（点子05遇到，按月截面最少股票数规则安全丢弃3个月）。
5. **来源混杂**：个股数据一半来自东财（含 turnover 列）、一半来自雅虎（无 turnover），各课代码已做列缺失兼容。
6. **iFinD 接口返回不稳定**：同一 query 三次返回三种结构、列顺序漂移（点子17实测），解析必须按表头名归一化。

## 与十倍股研究的复权教训呼应

工作区早前研究（`research/20260905_最近10年A股十倍股/`）曾发现选股引擎"区间涨跌幅:前复权"列复权虚增的问题（高分红股被严重虚增）。本套课程全部使用**前复权价格自己计算收益**，不复信任何引擎现成涨幅列——这是贯穿 17 节课的纪律。
