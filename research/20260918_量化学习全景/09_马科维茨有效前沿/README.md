# 09 马科维茨有效前沿 —— 1952年至今所有配置方法的起点

> 一句话：把"配钱"变成一个凸优化问题，然后亲眼看着**估计误差**把这个漂亮的数学玩具在样本外打回原形。
>
> 全部基于 `data/cache/` 10 个真实行业板块（银行/证券/保险/白酒/半导体/医疗器械/房地产开发/汽车整车/煤炭/电力），
> 共同重叠区间 **2022-01-07 ~ 2026-09-18（240 个周收益样本）**，随机种子 42，单文件可跑通，实测运行约 4 秒。

## 1. 这节课学什么

1952 年，25 岁的研究生 Harry Markowitz 在《Journal of Finance》发表了《Portfolio Selection》，
第一次把"投资"从选好股票变成了解一个优化问题，1990 年拿了诺贝尔经济学奖。这一节课你将：

1. **学会均值-方差框架**：用均值向量 μ 和协方差矩阵 Σ 两个统计量，把组合选择写成凸优化（GMV / 目标收益最小方差 / 最大夏普三类问题）；
2. **看懂有效前沿**：为什么 2000 个随机组合全部躺在前沿内侧（分散化的几何直觉），以及允许卖空时前沿为什么向左扩展；
3. **直面本课灵魂——估计误差**：用"过去 52 周估计 → 优化最大夏普 → 持有未来 13 周"的滚动实验，
   亲眼看到样本内最优夏普 **1.15** 在样本外变成 **-0.24**（落差 **1.38**），
   而什么都不优化的**等权组合样本外夏普 0.06，打赢了滚动再优化的最大夏普组合**——
   这正是 DeMiguel 等（2009, RFS）《Optimal Versus Naive Diversification》的核心结论在我们自己数据上的复现。

学完这课你就明白：为什么业界很少直接用"最大夏普优化"的原始输出，而 GMV、风险平价、约束加收缩估计成了主流。

## 2. 核心概念

### 2.1 均值-方差框架的三个公式

对 n 个资产，权重向量 w（和为 1），组合的收益与风险就是两个数：

```
组合年化收益：μ_p = wᵀμ            （μ_i = 第 i 个资产的年化均值）
组合年化方差：σ_p² = wᵀΣw          （Σ = 年化协方差矩阵）
夏普比率：    SR = (μ_p − rf) / σ_p （本课 rf = 2%）
```

三类经典优化问题（本课全部实现，且都加了 `sum(w)=1` 与 `w>=0`）：

| 问题 | 数学形式 | 直觉 |
|---|---|---|
| 全局最小方差 GMV | min wᵀΣw | "最稳"的组合，**完全不看 μ** |
| 给定目标收益的最小方差 | min wᵀΣw s.t. μᵀw = r* | 把目标收益从低到高扫一遍 → 有效前沿 |
| 最大夏普（切点组合） | max (wᵀμ − rf)/√(wᵀΣw) | 从 rf 出发"最陡"的那条射线碰到的前沿点 |

### 2.2 协方差矩阵与分散化：分散化的地板是"平均相关"

把 σ_p² = wᵀΣw 展开就是 ΣᵢΣⱼ wᵢwⱼσᵢⱼ。等权 N 个波动同为 σ 的资产时，
σ_p² → ρσ²（N→∞），**ρ 就是平均相关系数——分散化只能消掉个股权重的特异波动，消不掉"大家一起跌"的系统性部分**。

本课实测（图01）：10 个行业 45 对相关系数的平均值为 **0.28**，这就是这套行业组合分散化能力的"地板"。
分散化机会在相关性低的地方：**半导体-银行（-0.05）、半导体-煤炭（0.00）、医疗器械-银行（0.04）**；
而保险-证券（0.71）、保险-白酒（0.64）、医疗器械-汽车整车（0.61）这种高相关对，同时持有基本没有分散效果。

### 2.3 GMV 为什么不受均值估计误差影响（最重要的一条对比线索）

注意 GMV 的目标函数 min wᵀΣw 里**根本没有 μ**——它只吃协方差矩阵。
而协方差（波动率、相关性）跨期相当稳定，均值却极难估计：年化 25% 波动的资产，用一年数据估均值的标准误约 25%/√1年 ≈ 25% 个百分点，均值估计的置信区间宽得能开卡车。
所以理论上 GMV 天生对估计误差免疫；最大夏普则是 μ 的"放大器"。实验结果完全支持这一点（见 §5 绩效表）：
滚动 GMV 的波动始终压得住（18.06% < 等权 20.73%），而滚动最大夏普直接崩盘。

### 2.4 最大夏普组合与它的"凸化技巧"

max (wᵀμ − rf)/√(wᵀΣw) 是个**非凸**的分式规划，cvxpy 直接写不出来。
标准做法（Cornuejols & Tütüncü 教科书技巧）：令 y = w/κ（κ>0），等价于凸问题

```
min yᵀΣy   s.t.  (μ − rf)ᵀy = 1,  y ≥ 0        然后还原 w = y / sum(y)
```

本课实测（全样本）：最大夏普组合 = **房地产开发 71% + 半导体 29%**，只有两个资产，
波动 62.05%——优化器拿到微小的均值差异后会毫不犹豫地把你推到角落，这就是"押注少数资产"的由来（图05）。

### 2.5 为什么"估计误差"是 MPT 的阿喀琉斯之踵

优化器是**误差放大器**：μ 里 1 个百分点的估计噪声，经过"最大化收益/风险之比"这个过程的挑选，
会变成权重上几十个百分点的摆动。链条是：μ̂ 有噪声 → 优化器专挑"μ̂ 恰好高"的资产重仓 → 这些资产的真实 μ 并不高 → 样本内夏普虚高、样本外还债。
本课数字：平均样本内最优夏普 **1.15** → 样本外实际 **-0.24**，落差 **1.38**，直接打穿零轴；
同时滚动优化每 13 周换一次权重，权重摆动本身又引入额外的"统计换手"损耗（滚动版年化 -6.63%、回撤 -56.67%）。
**等权组合样本外夏普 0.06 > 滚动最大夏普 -0.24**——"优化打输等权"正是本课核心发现之一，如实呈现，不粉饰。

### 2.6 约束的作用：最便宜的"正则化"

不允许卖空（w≥0）这个约束看起来限制了自由，实际上砍掉了优化器最危险的动作——
凭空造出"+150% 做多 A、-80% 做空 B"的杠杆组合。图03 显示：允许卖空的前沿整体向左上扩展（同收益更低波动），
但那是在卖空免费、协方差矩阵估计精准的理想世界里；当估计有噪声时，杠杆会把估计误差一起放大。
约束 = 把"你不知道的东西"造成的伤害封顶。业界实战中还会再加单资产上限（如 ≤30%）进一步压制集中度。

**怎么读这张表（如实呈现，不粉饰）：**

- **夏普落差**：滚动实验里，每个估计窗内优化器承诺的平均夏普是 **1.15**，样本外实际只有 **-0.24**——

- **等权打赢了滚动优化的最大夏普**（0.06 vs -0.24）。这与 DeMiguel 等（2009）"14 个等权/先验组合很难被均值-方差优化打败"的结论一致。

  同一方法的滚动版 -0.24 才是其真实期望。**同一方法论，换个调仓节奏结论就翻转（0.43 vs -0.24），这种不稳健本身就是估计误差的证据。**

  但"只依赖协方差"的 GMV 至少兑现了降波动承诺——这就是为什么业界宁可要 GMV/风险平价，也不信最大夏普。
- 背景要诚实：样本外 2023-2026 恰逢 10 个行业里 5 个年化为负（白酒 -14.5%、证券 -10.0%、医疗器械 -12.1%、银行 -1.0%、汽车整车 -0.6%），

## 6. 常见的坑

1. **频率年化用错倍数**：本课是周频 → 均值×52、协方差×52、波动×√52。日频则是均值×244（A股年交易日）或×252（美股），协方差×244、波动×√244。把周频当日频×244，年化收益直接虚增约 4.7 倍；把日频只×52，波动会缩水一半。年化倍数与采样频率必须严格对应，夏普比率的分子分母倍数不一致会让数值完全失真。
2. **协方差矩阵非正定**：资产数 n 接近甚至超过样本数 T 时（如用 240 周估 500 只股票），样本协方差奇异/病态，`quad_form` 直接报错或优化输出疯狂权重。本课 n=10、T=52~240，且用了 `cp.psd_wrap` 防数值毛刺；实战请用 Ledoit-Wolf 收缩（`sklearn.covariance.LedoitWolf`）或指数衰减加权协方差。
3. **把有效前沿当成可实现的承诺**：前沿上的每个点都是用"同一批历史数据估出的 μ̂、Σ̂"算出来的，它回答的是"过去如果我知道参数会怎样"，不是"未来你会得到什么"。本课图04 就是前沿在时间上的真实面貌：样本内 1.15 的夏普，样本外是 -0.24。销售材料里那些"最优配置年化 XX%"曲线，几乎全是这条坑。
4. **忘了约束卖空，得到离谱杠杆组合**：不加 `w>=0` 时，优化器为了逼近最大夏普会自然给出"+130% 做多、-30% 做空"式组合（权重和仍为 1！），波动被杠杆放大到不可交易；卖空成本与保证金在模型里通常是 0，等于白送收益。本课所有优化默认 `allow_short=False`，图03 专门对比了两个世界。
5. **（附送）全样本优化 = 未来函数**：用包含 2026 年的数据算出的"最优组合"再去评价 2023-2026，等于先看答案再考试。固定权重组合必须只用"时点之前"的数据估计（本课 L282 的切片纪律），滚动实验的整个设计就是为了防这一条。

## 7. 延伸思考（练习）

1. **估计窗口的长度悖论**：把 `EST_WEEKS` 从 52 改成 26 和 104，重跑滚动实验。窗口越短参数越"新鲜"但噪声越大，越长越稳但越滞后——落差 1.38 会怎么变？是否存在一个"最不坏"的窗口？（提示：三个数字都记下来，你会发现没有一个窗口能让优化打赢等权。）
2. **收缩估计能救回多少落差**：用 `sklearn.covariance.LedoitWolf().fit(R_tr)` 替换滚动实验里的 `R_tr.cov()`，重跑。协方差噪声被压掉后，样本外夏普从 -0.24 回升多少？你会发现均值估计误差才是大头——这自然引出下一课"风险平价：干脆不预测收益"。
3. **给优化器上"枷锁"**：在最大夏普问题上追加单资产上限 `w <= 0.3`，重跑全样本优化与滚动实验。权重从"71%+29%"变成什么样？样本外夏普改善多少？（这就是业界说的"约束是最好的正则化"，可以直接对照图05 画第四根柱子。）
