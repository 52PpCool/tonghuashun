## 2. 核心概念

### 2.1 2×3 双重排序的设计逻辑

每年 6 月底，把 NYSE/AMEX/NASDAQ 全部股票按**两个维度**各切一刀：

- **维度一：市值（ME）**，按中位数分成 大(Big) / 小(Small) 两组；
- **维度二：账面市值比 B/M**，按 30%/70% 分位切成 成长(LoBM) / 中性(BM2) / 价值(HiBM) 三组。

两个维度交叉 → **2×3 = 6 个组合**：

| | 成长(LoBM) | 中性(BM2) | 价值(HiBM) |
|---|---|---|---|
| **小盘** | SG 小盘成长 | SN 小盘中性 | SV 小盘价值 |
| **大盘** | BG 大盘成长 | BN 大盘中性 | BV 大盘价值 |

关键设计：**分组用 NYSE 纽交所的分位数**（不让小股票多的交易所稀释断点），组合持有到次年 6 月（避免频繁换手），本课用的收益是组合形成后的月度收益。文件里列名 `SMALL LoBM / ME1 BM2 / SMALL HiBM / BIG LoBM / ME2 BM2 / BIG HiBM`，本课统一映射为 `SG/SN/SV/BG/BN/BV`（`COL_MAP`，main.py 第 54 行）。

### 2.2 SMB / HML 的构造公式

因子不是"算出来的指标"，而是**用这 6 个组合拼出来的多空组合**（main.py 第 205-206 行）：

```
SMB（Small Minus Big，规模因子）
    = (SV + SN + SG) / 3  −  (BV + BN + BG) / 3
    = 小盘三个组合等权平均  减  大盘三个组合等权平均

HML（High Minus Low，价值因子）
    = (SV + BV) / 2  −  (SG + BG) / 2
    = 两个价值组合平均  减  两个成长组合平均
```

为什么 SMB 内部要**三个组合等权平均**？因为小盘三组合里也混着成长/价值风格——三者平均后风格相互抵消，剩下的才是"纯规模"；HML 同理：大小盘各自配平，剩下的才是"纯价值"。

### 2.3 为什么用市值加权（value-weighted）

六个组合内部按**市值加权**：大公司话语权大，这才代表"全体投资者平均真实持有的组合"。若用等权（equal-weighted），小股票被放大几十倍，组合收益会被流动性差、交易成本高的股票主导——**学术上可得，实操上买不到**。
这正是 French 文件里 Value-Weighted 段和 Equal-Weighted 段并存的原因：前者用来构造官方因子，后者常用来做稳健性检验。**拿错一段，因子数值全错**（见"常见的坑"第 1 条）。

### 2.4 因子 = 多空对冲组合：换个视角看"因子"

把 SMB/HML 看成一张**交易单**：`SMB = 做多小盘 + 做空大盘`。这个视角带来三个推论：

- 它有**净值曲线**（本课图 3），可以复利、可以回撤——1926-07 至 2026-07，SMB 多空累计 4.10 倍、HML 多空累计 34.24 倍（不含交易成本与做空成本）；
- 它**不需要预测市场**：多空对冲后市场 beta 理论上 ≈ 0，赚的是结构溢价；
- 它的收益 = **被消除的共同风险后的残差定价**。FF 三因子回归（第 06 课）里的 β·因子，就是在问"你的策略有多少收益其实是这三张多空单的影子"。

### 2.5 因子拥挤与失效周期

因子收益来自"承担了别人不愿承担的风险 + 别人没注意到的错误定价"。一旦广为人知：

- 资金涌入把溢价**交易掉**（错误定价消失）；
- 拥挤的持仓在压力时期**踩踏**（2020 年 9 月前后价值因子挤爆就是典型案例）；
- 宏观 regimes 变迁（低利率利久期资产 → 利成长股）。

数据里看得非常直白（图 4 / 图 3b，真实输出）：HML 月均 1940s +0.798%、2000s +0.663%（互联网泡沫破裂后价值大反弹），但 **2010s 月均 −0.195%（年化 −2.62%），是全部 11 个年代中唯一深度为负的年代**；2010-01 起累计最低跌到 0.508 倍（2020-09），到 2026-07 也只回到 0.848 倍——**17 年价值多空仍亏 15%**。因子不是物理定律，是有生命周期、会拥挤踩踏的策略资产。

### 2.6 数据文件解析的工程活

French 的 CSV **不是**规整表格，而是 1980 年代风格的报表拼接：头部十几行说明文字，然后依次是
`Average Value Weighted Returns -- Monthly`、`Average Equal Weighted Returns -- Monthly`、年度两个段、`Number of Firms in Portfolios`、`Average Market Cap`、Sum of BE/ME 等十余个数据段，每段自带列头，段间空行分隔，缺失值约定为 `-99.99 / -999`。
直接 `pd.read_csv` 必然爆炸。解析三步法（main.py 第 128-190 行）：**定位段标题 → 读列头 → 只接收"6 位年月开头"的行，遇敌即停**。这种"脏格式防御性解析"是接入任何学术/供应商数据（WRDS、CSDC、Wind 导出）的基本功。

**A股粗糙代理（图 6，务必只看方法不看结论）：**

## 6. 常见的坑（本课真实踩过/防住的）

1. **Value-Weighted 与 Equal-Weighted 段拿错**。文件里两段结构一模一样、只差段标题一行。EW 段的小盘收益被放大，用它构造的"SMB"会虚高一截，而且**不会报错**——错误会安静地污染后面所有回归。防御：像本课一样先定位段标题、遇非数据行即停，并在解析后打印首末月份与月数（本课输出 1201 个月、192607~202607，与官方一致才算解析成功）。
2. **单位混乱：% 与小数差 100 倍**。French 文件收益单位是 %（1.0866 表示 +1.0866%），`pct_change()` 给的是小数（0.010866）。本课第一版 A 股部分就真实翻车：把小数序列喂给吃百分数的年化函数，沪深300 年化被打成 0.04%（真实是 2.47%），差 100 倍。**防御：统一单位并在代码里显式 ×100（main.py L319-324），任何年化/累计先问一句"这是 % 还是小数"。** 复权同理：价格序列必须同口径（前复权对前复权），否则除息日会算出假暴跌。
3. **把因子长期均值当未来预期**。"HML 百年月均 +0.4%"很容易被写成"价值因子年化 5%，配置！"——但 2010s HML 月均 −0.195%、2010 年以来多空累计只有 0.848 倍。因子溢价有**巨大的年代方差**（图 4），任何"百年均值"都是被 1940s/2000s 撑起来的。正确用法：给溢价区间估计 + 承认失效期可能长达十年以上，再做决策。
4. **A股代理因子的幸存者偏差**。30 只股票全是 2026 年还活着的知名公司；2018 年退市/暴雷的（乐视、康美……）不在池子里，等于先删掉了"小盘亏损腿"最惨的部分再测小盘溢价。另外用**股价**排序分大小盘是刻意的错误示范（价格≠市值，茅台单价高≠市值大），本课保留它就是让你亲眼看到它分出来的是风格不是规模。真做因子必须：全市场池（含退市）、市值排序、月度/年度重建分组。
5. **缺失值哨兵**。French 文件用 `-99.99 / -999` 表示缺失，若不转 NaN，1926 年早期个别组合缺失月份会被当成"单月 −99.99%"直接打穿累计净值。本课在 L181 显式转换并打印缺失计数（本段实际缺失 0 个）。

## 7. 延伸思考（练习）

1. **加一腿 MOM**：从 French 官网再下载 `6_Portfolios_2x3_CSV.zip` 同族的动量数据（`10_Portfolios_Prior_12_2.zip` 或 2×3 动量六组合），照本课框架构造 UMD（动量因子），并与官方 `Mom_Factor` 对照。检查你的解析函数是否一行都不用改——这就是防御性解析的回报。
2. **等权 vs 市值权**：本课只解析了 VW 段；把 EW 段也解析出来，分别构造两个"SMB"，对比它们 1926 年以来的累计净值与分年代均值。想想：差异集中在哪些年代？这对"小盘溢价有多少是可交易的"意味着什么？
3. **A股代理的修正版**：把排序变量从"价格"换成"月成交额 × 价格"（粗糙流动性/规模代理），或直接用分组后两组的**市值加权**代替等权，重算代理 SMB，观察它与沪深300 的相关性从 −0.506 怎么变化。哪一步改变了对"规模暴露"的捕捉，哪一步只是换了噪声？
