# 03 海龟交易法则 —— 把交易写成机器可执行的规则

> 本课完整复刻 1983 年"海龟交易员"实验中的**系统一（System 1，短周期版）**：
> 20日唐奇安通道突破入场、10日通道下破/2N止损离场、波动率倒数仓位、0.5N金字塔加仓。
> 标的：贵州茅台 600519（前复权日K，2015-01-05 ~ 2026-09-17，共 2845 个交易日）。
> 全部结果由 `main.py` 实际运行产出，数字均可复现。

---

## 一、这节课学什么

前两节课你可能已经见过"向量化"的回测：一行 `df['ret'] > 0` 就算完信号。
**这节课反过来：用清晰的事件循环（逐日 for 循环 + 状态机）写一个有"记忆"的策略。**

学完本课你应该能回答：

1. 什么是"规则化交易"——为什么海龟法则能被写成一张**流程图**，任何人执行结果都一样；
2. 什么是**状态机**——策略在"空仓 / 持仓 / 加仓中"不同状态下，同样的K线会触发完全不同的动作；
3. **ATR（N值）仓位法**——为什么"越波动买越少"能让每笔交易的风险均匀；
4. **止损为什么是趋势策略的生命线**——胜率只有 34% 的系统凭什么能赚钱；
5. 信号与执行为什么要**分离**（收盘出信号、次日开盘执行）——这是初学者回测造假的重灾区。

一句话总结本课：**趋势跟踪策略 = 低胜率 × 高盈亏比 + 严格止损 + 风险均匀的仓位**。

## 二、核心概念

### 2.1 唐奇安通道（Donchian Channel）

- **入场**：收盘价 > **前 20 日最高价**（不含当日）→ 明日开盘买入第 1 个单位；
- **离场**：收盘价 < **前 10 日最低价**（不含当日）→ 明日开盘全部卖出。

直觉：创 20 日新高 = 短期趋势向上被"证实"；跌回 10 日低点 = 趋势已坏，先走。
"不含当日"这一点极易写错：若通道把今天的价格也算进去，今天永远突破不了"包含自己的高点"，或产生未来函数。

> 注：海龟原版系统一还有"**跳过第一次突破**"过滤器（第一次突破不进场，等第二次突破或价格再走出 0.5N 再进），本课为教学清晰做了简化，没有实现该过滤器，属于对原版的**放宽**（交易次数会偏多）。

### 2.2 ATR 与 N 值

N = ATR(20)，即"真实波幅 TR"的 20 日均值：

```
TR   = max(当日高-低, |当日高-昨收|, |当日低-昨收|)   # 跳空也要算进波动
N    = TR 的 20 日平均
```

N 是整个系统的"度量衡"：仓位大小用 N 定、加仓间距用 N 量（0.5N）、止损距离用 N 划（2N）。
茅台在 2015 年 N≈2.8 元，2022 年 N≈45.6 元——同一套规则，N 自动适配了价格量级的巨大变化。

### 2.3 波动率倒数仓位：为什么它让"风险均匀"

每个交易单位（Unit）的股数：

```
Unit股数 = 账户权益 × 1% / N        （A股再向下取整到100股）
```

**直觉：越波动买越少。** 不管标的波动是大是小，价格反向走 1N，这一个单位都大约亏掉账户的 1%：

- 2015 年茅台 N=2.82：单位 = 100万×1%/2.82 ≈ 3546 股（约47万元市值）；
- 2022 年茅台 N=45.60：单位 = 396万×1%/45.6 ≈ 868 → 800 股（约111万元市值）。

两种情形下"价格每动 1N，账户亏 1%"完全一致。**海龟不是在分配"钱"，而是在分配"风险"**——这是它和"每次买10万块"式朴素仓位法的本质区别。

> A股现实约束：茅台这种"价格高 + 波动大"的股票，一个单位的市值常达到账户的 30%~50%，加到第 3、4 单位时现金就不够了。原版海龟做期货，有杠杆，1 个单位名义价值可以远超账户；A 股现货只能全现金，所以代码里对每个单位做了**现金上限截断**（`main.py` 第 173-175 行）。实际运行中它真实生效了：代表性交易的最后一个单位，理论应买约 800 股，因现金只剩 106,716 元，被截断为 300 股。

### 2.4 止损：趋势策略的生命线

- 初始止损 = 入场价 − 2N；
- 每加仓一个单位，**整体止损上移**为"最新入场价 − 2N"（4 个单位共用同一条线）。

本课实测：44 笔交易**只有 15 笔盈利（胜率 34.1%），29 笔亏损**——单看胜率是糟糕的系统。但盈亏比高达 **4.47**（盈利 15 笔平均 +315,068 元/笔、亏损 29 笔平均 -70,548 元/笔，全期每笔平均盈亏 +60,912 元，靠 2020 年 +974,190 元、2019 年 +706,441 元这样的大趋势单拉高平均；亏损被 2N 止损压在 -273,689 元以内）。

这就是趋势跟踪的数学结构：**大部分时间小亏试错（被止损打掉），极少部分时间让利润在大趋势里奔跑**。止损不是防御措施，它就是这台机器的核心零件——没有 2N 止损，几次深亏就能抹掉几十次小赢积累的全部优势。离场原因分布也印证了机器在按设计工作：44 次离场中，"10日通道下破"23 次、"2N止损"21 次。

### 2.5 海龟实验的故事（为什么值得复刻）

1983 年，交易员理查德·丹尼斯（Richard Dennis）与合伙人威廉·埃克哈特（William Eckhardt）打赌：**伟大的交易员是天生的还是可以培养的？** 丹尼斯在报纸上刊登广告，招募了 20 多名几乎没有交易经验的新人（被称为"海龟"，源于丹尼斯在新加坡海龟养殖场的那句"我们要像养海龟一样培养交易员"），把一套完整规则教给他们：入场、仓位、加仓、止损、离场，全部量化。随后两年，海龟们为丹尼斯赚了超过 1 亿美元。

这个实验的深远意义不在收益率，而在它证明了：**一套写成明确规则的系统，可以复制给普通人并产生一致结果**。交易决策从"凭感觉"变成"按流程"，这就是今天量化投资行业的起点之一。本课就是把你放到"海龟学员"的位置：规则已给全，代码只是流程图的翻译。

> 小史料：海龟学员（含后来自立门户者）在随后几年累计为其赚取了上亿美元利润；这段故事最完整的公开记述见 Michael Covel《The Complete TurtleTrader》（中译《海龟交易法则》作者柯弗的另一本纪实）。数字历代转述有出入，但"规则可复制"这个结论从未被推翻。

## 三、代码怎么读：状态机（空仓 → 持仓 → 加仓 → 离场）

`main.py`（单文件自包含，全中文注释）的核心是一个逐日事件循环 + 两状态状态机。
**每个交易日只做三件事**（`run_backtest`，第 265-271 行）：

```
① 开盘：执行昨天收盘生成的挂单        → execute_orders（第 224 行）
② 收盘：按收盘价记录账户总权益        → equity_curve（第 270 行）
③ 收盘：用当日数据评估信号，写入 pending，次日才执行 → evaluate_signals（第 241 行）
```

状态转移图：

```
[FLAT 空仓] --收盘>前20日最高--> [LONG 持仓·第1单位] --收盘≥最新入场价+0.5N--> [LONG 第2/3/4单位]
    ^                                                                    |
    |            ①收盘<止损价(最新入场价-2N) 或 ②收盘<前10日最低            |
    +------------------------------- 全部卖出 ----------------------------+
```

对应代码位置（行号为当前 `main.py` 实际行号）：

| 环节 | 函数 | 行号 | 说明 |
|---|---|---|---|
| 状态定义 | `STATE_FLAT / STATE_LONG` | 128-129 | 两个状态 |
| 仓位计算 | `TurtleTrader._unit_shares` | 154 | 波动率倒数 + 现金上限截断 |
| 买入执行 | `TurtleTrader._do_buy` | 179 | 开盘成交、止损整体上移（第 191 行） |
| 卖出执行 | `TurtleTrader._do_sell_all` | 199 | 含佣金+印花税+滑点，状态复位（第 215 行） |
| 开盘执行 | `TurtleTrader.execute_orders` | 224 | 空仓→开仓（233-234 行），持仓→加仓 |
| 收盘决策 | `TurtleTrader.evaluate_signals` | 241 | ①止损优先（245）→ ②通道下破（248）→ ③0.5N加仓（251）→ 空仓看突破（256） |

**"信号与执行分离"是本代码的灵魂**：收盘只生成 `pending` 订单，绝不动账；
次日开盘才按 `open × (1±滑点)` 成交。这同时解决两件事——
(a) 不偷看未来（收盘才能算出的信号不可能影响当天的成交价）；
(b) 天然满足 A 股 **T+1**（今天开盘买的，最早明天开盘才可能卖）。

其余部分：数据与指标 `load_data`(71) / `add_indicators`(78)；基准 `buy_hold_equity`(275)；
绩效 `perf_stats`(288) / `trade_stats`(301)；交易明细 `trades_to_frame`(315)；
绘图 `plot01`(356) / `plot02`(386) / `plot03`(411)；主流程 `main`(459)。

期末权益：策略 3,680,134 元 vs 买入持有 10,010,265 元（初始 100 万）。

**如实结论：本例中海龟策略大幅跑输买入持有。** 必须讲清为什么：

1. **单边趋势品种太少。** 茅台 2015-2021 是罕见的长牛单边市（买入持有的黄金土壤），但 2021 年后转入长期宽幅震荡。突破策略天然是"买贵卖贱"：每次都追在 20 日新高、割在 10 日新低，震荡市里反复被"假突破"打脸——44 笔交易里 29 笔亏损就是这么来的。唐奇安突破在**趋势市吃肉、震荡市挨刀**，而单一股票无法保证你总是处在趋势市。
2. **现金上限削弱了复利引擎。** 原版海龟靠杠杆让 4 个单位全部建满；A 股现货加到第 2、3 个单位就常被现金卡住（本例 44 笔交易共建成 98 个单位：1 单位 10 笔、2 单位 16 笔、3 单位 16 笔、满 4 单位仅 2 笔，且后段单位的股数常被现金上限截断），大趋势里的利润吃不满。
3. **它赢在哪里也要看到：** 回撤 -30.5% 对 -47.5%，波动 17.4% 对 29.7%。2021 年茅台见顶后买入持有从高点腰斩再腰斩，海龟靠着 2N 止损把水下时间大大缩短——**用收益率换生存质量，这正是趋势系统的设计目标**。夏普差距（0.57 vs 0.67）也远小于收益差距。

## 六、常见的坑

1. **用当日高点判断突破、当日就入场（前视偏差 + 不可能成交）。**
   "今天最高价突破了 20 日高点"是收盘后才知道的事实，当日盘中你并不知道今天是"突破日"。若回测里写成 `high > donchian_up(含当日)` 就当日收盘成交，收益会被系统性高估。正确做法如本课：**通道不含当日（`shift(1)`），收盘确认信号、次日开盘成交**（`add_indicators` 第 96-97 行、`evaluate_signals` 第 241 行）。

2. **止损价用未复权价或忘记复权切换。**
   茅台 2015 年至今有分红送转，前复权价和当年真实成交价差别巨大（本课数据里 2015 年股价显示约 140 元，是前复权后的数字）。若 N 和入场价用前复权数据算，止损线却按脑海里的"真实价格"设，或者回测中途换了复权口径，止损位会整体错位。规则：**整条链路（N、入场、止损、通道）必须用同一份复权数据**。

3. **忽略 A 股 T+1 与 100 股整数倍。**
   海龟原版是期货：盘中触价立即成交、可随时平仓。A 股当日买入的股票当天不能卖——如果你让"止损信号"当日即时成交，就隐性使用了 T+0；如果单位股数不取整到 100 股，订单根本发不出去。本课的做法：收盘信号次日开盘执行（天然 T+1），股数按 100 股向下取整（`_unit_shares` 第 172、175 行）。

4. **忘掉卖出侧的费用结构。**
   A 股费用不对称：买入只有佣金，卖出是佣金 + 印花税（千 0.5，2023-08 起）。本例 44 笔交易全期摩擦成本合计 **111,095 元**（买入侧 27,267 元 + 卖出侧 83,828 元，约合初始资金的 11%）——高换手策略里漏算卖出印花税会显著美化结果。参数见 `main.py` 第 51-53 行。

5. **把海龟直接搬到 A 股现货却忽略杠杆差异。**
   原版单位仓位 = 1%风险预算/N，期货下一单位名义价值可达账户的几倍；A 股现金买入，一个单位就可能占账户 40%，4 个单位根本建不满（本例 44 笔中只有 2 笔建满 4 单位）。这不是 bug 而是市场结构差异，必须在解读结果时心里有数。

## 七、延伸思考（练习）

1. **改参数做敏感性实验**：把 `ENTRY_WIN` 从 20 改成 55（即海龟"系统二"，长周期版）、`EXIT_WIN` 从 10 改成 20，重跑。交易次数、胜率、盈亏比怎么变？验证一句老话："系统一抓小趋势、系统二抓大趋势，规则相同、参数决定性格。"
2. **实现"跳过第一次突破"过滤器**：真系统一在止损离场后，若价格再创新高属于"第一次突破"，应放弃，等到"第二次突破"才进场。提示：在 `evaluate_signals`（第 256 行附近）加一个 `self._last_exit_was_stop` 标记，统计这一改动对 44 笔交易里那 29 笔亏损的影响。
3. **风险均匀吗？**：把 `trades.csv` 里每笔的 `pnl` 除以该笔入场日的账户权益，画出"每笔风险贡献"的分布；再对比"固定买入 10 万元/单位"的版本（把 `_unit_shares` 改成常数）。用数据回答：波动率倒数仓位到底把什么变得均匀了——收益率，还是风险？
4. **多标的思考题（不改代码）**：海龟原版同时在多市场捕趋势，用"单位风险=1%账户"把每个市场的波动拉平。如果给你 `data/cache/` 里其他 30 只股票，如何把本课的单标的 `TurtleTrader` 扩展成共享一个现金池的多标的组合？瓶颈在哪（现金竞争、同日多信号、状态数爆炸）？
