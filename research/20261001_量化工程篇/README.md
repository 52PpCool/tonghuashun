## 共享库 quantlab/（后续研究的可复用资产）

- `engine.py` —— A股约束版事件驱动回测引擎（`fill_order` 撮合函数被 39 回测器与
  40 纸面运行器**共用同一份代码**；`Account/BrokerConfig/Strategy/Backtester`）。
  v1 单文件版备份于 `engine_v1_backup.py`（重构前后对照）。
- `data.py` —— 数据加载（全景课缓存 + 37/38 课新浪源留档）。
- `datafeed.py` —— 网络取数（新浪源，限速+退避；前复权增量陷阱文档化）。

## 一键复现

```bash
VENV=../20260918_量化学习全景/.venv/bin/python
cd 39_自写事件驱动引擎 && $VENV main.py          # 三实验，约20秒
cd ../40_纸面交易运行器 && $VENV main.py --init --live-refresh --backfill 2026-06-01:2026-09-30 --report
cd ../41_数据仓库与时点数据 && $VENV main.py --build --report   # 首次联网约2-3分钟（需 duckdb）
cd ../42_画像变策略 && $VENV main.py             # 约1分钟
```

## 全篇诚实边界（汇总）

1. 价格均为前复权日K，封板判定用"一字板"近似（对复权舍入免疫，但"非一字开盘封死"未建模）。
2. 恒定滑点是粗近似；无融资融券；纸面交易不接真实券商。
3. 行业分类无历史数据（iFinD/免费源均无）——38/41/42 三课的"前视分类债"记账保留。
4. 42 课的母体是结果样本（循环论证），其结论是"区分度在组合层面衰减"，
   **不是任何可投资策略的收益证据**。
