## 一、这节课学什么

1. **仓位是乘法问题，不是加法问题。** 亏 50% 要赚 100% 才能回本——收益不可加，
   长期成绩由"每期对数收益的期望"（几何增长）决定。Kelly 公式就是让这个期望最大的仓位。
2. **Kelly 是一条凹曲线，不是最优点那么简单。** 少押只是少赚（曲线左侧平缓），
   多押加速变负（右侧陡峭），**超过 2 倍 Kelly 增长率转负**，全下注终值趋零。
   图 01 是全课最震撼的一张图：峰在 f*=0.10，f=0.20 增长归零，f≥1 全趴在破产地板上。
3. **现实没有 μ。** 你只有"过去一段时间的 μ̂"。实验证明：真 Kelly 年化对数增长 11.09%，
   用 120 日滚动估计的"估计 Kelly"变成 **−11.52%**；打折（半 Kelly、固定 50%）才是活路。
4. **回撤是比增长更硬的约束。** 用茅台真实参数模拟：满仓 Kelly（2.20 倍）4 年内
   **92.4% 概率回撤超 50%**，半 Kelly 降到 24.5%——这就是机构用"分数 Kelly"的原因。
5. **同样的弱信号，仓位规则决定你拿到哪段收益与回撤。** MA20 信号 × 四种仓位规则的
   真实回测：信号本身弱没关系，本课主角是仓位。

先修：01（收益与风险的度量）、11（蒙特卡洛模拟）。新工具只有一个：`np.random.default_rng(42)`。

## 二、核心概念

### 2.1 离散版 Kelly：f* = p − (1−p)/b

二结果赌局：赢的概率 p，赢时每 1 元押注赚 b 元；输的概率 1−p，输掉押注。
每期押净值的 f 比例，净值乘数：赢 → (1+b·f)，输 → (1−f)。

**推导（代数全过程）**：长期增长率用每期对数收益期望度量

```
g(f) = p·ln(1+b·f) + (1−p)·ln(1−f)
令 g'(f)=0：  p·b/(1+b·f) − (1−p)/(1−f) = 0
⇒ p·b·(1−f) = (1−p)·(1+b·f)
⇒ p·b − p·b·f = (1−p) + (1−p)·b·f
⇒ p·b − (1−p) = b·f·(p+1−p) = b·f
⇒ f* = (p·b − (1−p))/b = p − (1−p)/b
```

g''(f) = −p·b²/(1+bf)² − (1−p)/(1−f)² < 0，g 是凹函数，f* 是唯一峰值。
本课参数 p=0.55、b=1：**f\* = 0.55 − 0.45 = 0.10**，理论峰值 g=0.5008%/期
（若一年赌 252 期独立局，等效年化约 126%——注意这只是赌局等效，不是真实年化承诺）。
蒙特卡洛验证：峰值出现在 **f=0.100、g=0.5068%/期**，与理论一致（10000 路径×1000 期）。

### 2.2 连续版 Kelly：f* = μ/σ²

市场每期收益 r~N(μ,σ²)，净值 W′=W·(1+f·r)。泰勒展开 ln(1+x)=x−x²/2+…：

```
E[ln(1+f·r)] ≈ f·μ − f²σ²/2    （凹函数）
对 f 求导取零：μ − f·σ² = 0  ⇒  f* = μ/σ²，最大增长率 g* = μ²/(2σ²) = 夏普²/2
```

直觉：**分子是你能吃到的"漂移"，分母是你必须交的"方差税"，仓位=漂移÷方差**。
用茅台 2015-01-05 ~ 2026-09-17 真实日收益（n=2844）：日 μ=0.0766%、σ=1.868%
（年化 19.3% / 29.6%），**f\* = μ/σ² = 2.20**——满仓 Kelly ≈ **2.20 倍杠杆**（1.20 倍需融资）。
对照：上证指数（2010 起，n=4054）μ 年化仅 1.1%、σ 19.8%，**f\* = 0.28**——指数只配放 28% 仓位。
**夏普决定仓位**：茅台夏普 0.65、上证 0.06，Kelly 仓位差了 8 倍。（注意口径：这里的
"夏普"是 Kelly 理论口径 μ/σ——该推导的世界里没有无风险资产，不减 rf；与第 5 部分回测表的
rf=2% 口径不同。）

为什么现实没人这么干？见 2.3、2.5 与"常见的坑"。

### 2.3 为什么全下注是自杀（几何增长最大化）

全下注（f=1）在离散赌局里**输一次净值就归零**，之后永远无法翻本——乘法里 0 乘任何数都是 0。
蒙特卡洛（10000 条×1000 期）：**f=1.0 的终值中位数 = 0.0000 倍**；同样运气下半 Kelly（f=0.05）
终值中位数 **47.12 倍**、Kelly（f=0.10）**182.92 倍**（图 02：30 条样本路径，全下注全部在第几期
首次亏损时出局）。f=1.5（1.5 倍杠杆）的蒙特卡洛增长率为 **−2.763%/期**——趴在破产地板上
（终值为 0，数值上按 1e-12 截断折算：ln(1e-12)/1000）。

关键不对称：f<f\* 少赚，f>f\* 加速亏，**g(f)<0 当且仅当 f>2f\***（本例 f=0.20 处
g≈−0.0016~-0.0138%/期，已过零点）。这就是"2 倍 Kelly 是不归点"。

### 2.4 分数 Kelly 的实践理由

两个独立理由，本课都用数字验证了：

- **回撤理由（第 4 部分，茅台参数市场）**：f\*=2.20 下，
  | 仓位 | 回撤中位数 | P(回撤>50%) |
  |---|---|---|
  | 半Kelly f=1.10 | 41.1% | 24.5% |
  | Kelly f=2.20 | 68.8% | **92.4%** |
  | 2×Kelly f=4.39 | 94.5% | **100%** |
  | 无杠杆满仓 f=1.00（参考） | 38.0% | 17.3% |

  满仓 Kelly 几乎必然腰斩——增长最大但中途被迫下车的概率极高；半 Kelly 用
  3/4 的增长率换来回撤中位数砍掉近 28 个百分点（41.1% vs 68.8%）。
- **估计误差理由（第 3 部分）**：见 2.5。

### 2.5 参数估计误差：你永远不知道真实的 μ

实验设计：真实市场 r~N(μ=0.06%/日, σ=2%/日)（真 Kelly=1.50 倍），10000 条路径×1000 期；
交易者只能用**过去 120 日**估 μ̂、σ̂ 定仓（μ̂ 的标准误=σ/√120=0.183%/日，是真 μ 的 3 倍多！）。
四种（加一个对照共五种）规则的结果：

| 规则 | 年化对数增长 | 终值中位 | 回撤中位 | P(回撤>50%) | 平均仓位 |
|---|---|---|---|---|---|
| 真Kelly（上帝视角，1.50倍） | **11.09%** | 1.54 | 59.5% | 74.3% | 1.50倍 |
| 估计Kelly（120日滚动，≤5倍） | **−11.52%** | 0.48 | 86.5% | 99.9% | 1.84倍 |
| 半Kelly（0.5×估计，≤2.5倍） | 4.10% | 1.01 | 57.3% | 74.7% | 0.92倍 |
| 真半Kelly（0.75倍常数，对照） | 8.38% | 1.39 | 34.3% | 11.2% | 0.75倍 |
| 固定50%仓位 | 6.22% | 1.28 | **24.0%** | **1.0%** | 0.50倍 |

三个读法：

1. **估计误差把 +11% 变成 −11.5%**：μ̂ 噪声导致仓位在 0 与 5 倍之间乱跳（37% 天数因
   μ̂<0 空仓、踩雷时又是高杠杆），终值中位数只有 0.48 倍——**满仓动态 Kelly 不如不做**。
2. **打折有效但不够**：半 Kelly（4.10%）比估计 Kelly 好，但仍远逊于同仓位水平的
   "真半 Kelly（0.75 倍常数）"的 8.38%——两者平均仓位都是 0.75 倍上下，
   差距**全部来自估计噪声**（真半 Kelly 回撤 34.3% vs 估计半 Kelly 57.3%）。
3. **最笨的固定 50% 增长 6.22%、回撤仅 24.0%、P(腰斩) 1%**——参数不确定时，
   "低而稳"常常赢"高而晃"。（理论校验：真 Kelly 最大增长 g\*=μ²/2σ²×252=11.34%，
   蒙特卡洛 11.09%，验证通过。）

### 2.6 波动率目标与 Kelly 的关系

- **波动率目标规则**：f = σ_target / σ_actual，使组合实现波动 f·σ_actual = σ_target。
  本课第 5 部分用 σ_target=10%（年化）、20 日滚动 σ 估计。
- **与 Kelly 同构**：Kelly f\* = μ/σ²。满仓 Kelly 的组合波动 = f\*·σ = μ/σ = **夏普**——
  茅台满仓 Kelly 组合年化波动 65%（夏普 0.65 的具象化）。所以"波动率目标 10%"
  相当于"假设夏普=0.10 的折扣版 Kelly"。写成与 Kelly 相同的"风险预算÷实际方差"形式：
  f = (σ_target·σ_actual)/σ_actual²——分子是你要的风险，分母是实际方差，与 f\*=μ/σ² 完全同构
  （有的教材速记作 f=目标σ/实际σ²，即把风险预算直接放在方差尺度上，本质一样）。
- 实测（茅台，MA20 信号内）：波动率目标 10% 平均仓位 22.6%，年化 7.74%、夏普 0.73、
  回撤 −18.4%（rf=2% 口径；波动只有全仓规则的 38%、回撤少 14.5 个百分点，代价是
  终值 2.39 倍 vs 全仓 6.74 倍——rf 口径下全仓夏普 0.78 还略高，但那是以深一倍的回撤换来的）。
  它自动在慢牛里多拿、在波动放大时减仓——**波动率目标是"不预测收益、只管理风险"
  的稳健版 Kelly**。

## 六、常见的坑

1. **用算术期望选仓位。** 赌局算术期望在 f≤1 时随 f 单调上升（p=0.55,b=1 时 E=+0.1f/期），
   按它选仓会得出"越多越好"。长期复利由**几何增长（对数期望）**支配，它是 f 的凹函数。
   一句话：**单期期望决定"平均你在哪"，对数期望决定"长期你在哪"。**
2. **把回测 μ 当真实 μ。** 本课茅台 f\*=2.20 的 95% 区间是 [0.23, 4.16]；第 3 部分里
   120 日 μ̂ 的标准误（0.183%/日）是真 μ（0.06%/日）的 3 倍。用回测全样本 μ 定杠杆，
   等于把估计值当成上帝视角——实验里这一步把 +11% 变成了 −11.5%。
3. **Kelly 假设参数平稳。** f\*=μ/σ² 隐含"明天的分布=过去的分布"。茅台 2015-2026 跨越
   白酒景气与调整周期，μ、σ 都在漂移；第 5 部分的"半 Kelly 动态"每 60 日重估，就是在
   承认参数不稳。任何"一次性算出永远用"的仓位都自带这个假设。
4. **赌局可加性 ≠ 市场时序依赖。** 离散赌局的终值只取决于总胜场（独立、可交换），
   所以扫描增长率一行代码就够（L130-132）；但看**路径最低点**（破产概率）和市场收益
   （自相关、肥尾、波动聚集）时顺序不能丢——第 6 部分就必须逐期 cumsum（L472）。
   把"1000 期独立赌局"的结论直接搬到"1000 天有时序依赖的市场"会低估尾部风险。
5. **杠杆版没算融资成本。** 连续 Kelly f\*=2.20 意味着 1.20 倍资金要融资。若融资利率 6%/年，
   相当于每天从 μ 里扣 1.2×6%/252≈0.029%/日——茅台 μ 只有 0.077%/日，f\* 会被打到约 1.1 倍。
   本课模拟（第 3、4 部分）为聚焦主问题未计融资成本，实盘必须重算：**f\* = (μ−r_f·(f−1))/σ²
   中的利率项会把"满仓 Kelly"大幅拉低**。
6. **对数收益与算术收益混用。** 估计 f\* 用对数收益 μ（可加、与 g 的定义一致）；
   净值模拟用简单收益 (1+r) 连乘。两者差 σ²/2（茅台年化差约 4.4 个百分点），
   混用会让 f\* 系统性偏高——本课代码里严格分开（L68-69）。

## 七、延伸思考（练习）

1. **算一下你自己的 Kelly。** 用 `data/cache/` 里任意一只股票（如 000858 五粮液）2015 年起的
   日收益重算第 2 部分：f\* 是多少？标准误多大？再用它的参数跑第 4 部分：半 Kelly 的
   P(回撤>50%) 是多少？把结果与茅台对比，解释夏普差异如何传导到仓位。
2. **给估计 Kelly 加"平滑"。** 第 3 部分中估计 Kelly 仓位在 0~5 倍乱跳。试着把 f̂ 改成
   `0.9×昨日仓位 + 0.1×新估计`（EMA 平滑）或把估计窗口拉长到 250 日，看年化增长与
   P(回撤>50%) 各变化多少。平滑能救回多少被估计噪声吃掉的收益？
3. **验证"半 Kelly 拿走 3/4 的增长"**。理论上 f=f\*/2 时 g=3g\*/4。在第 3 部分把真 Kelly
   从 1.50 倍换成 f\*∈{0.25,0.5,0.75,1.0,1.25,1.5} 常数扫描（复用 L125-141 的扫描思路），
   画出 g(f) 蒙特卡洛曲线，验证 0.75 倍仓位处是否 ≈ 8.5%（=11.34%×3/4）。
